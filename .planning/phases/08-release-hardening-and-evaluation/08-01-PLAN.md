## Design Locks

- **D1 Telemetry Probe Caching (TEL-01):**
  - `resource_telemetry.get_gpu_memory_info` caches the last valid GPU telemetry dictionary with a 5.0-second TTL using `time.monotonic()`.
  - Supports a `force_refresh: bool = False` parameter for benchmarks and profilers requiring immediate sampling.
- **D2 Loopback Endpoint Security (SEC-01):**
  - `LlamaCppProvider` validates that `base_url` host is in `{"127.0.0.1", "localhost", "::1"}` unless `allow_remote=True` is explicitly passed.
  - Non-loopback URLs raise `ValueError("Restricted endpoint: ... is not a local loopback address.")`.
- **D3 Informed Consent Disclosure & State Cleanup (PRIV-01, PRIV-02):**
  - Update `_render_consent_dialog_content` in `main.py` to clarify that transmitted document excerpts include extracted text, OCR, and visual element summaries.
  - Remove legacy `st.session_state.cloud_api_key` writes in `main.py` sidebar, relying strictly on `cloud_api_keys: dict[str, str]`.
- **D4 Stale Test Fixture Cleanup (TEST-01):**
  - Fix or remove `mock_groq_client` in `tests/conftest.py` so test fixtures remain clean and fully functional.
- **D5 Deterministic Dependency Pinning:**
  - Create `requirements-lock.txt` capturing exact package versions.
  - Ensure `requirements.txt` specifies verified production pins.
