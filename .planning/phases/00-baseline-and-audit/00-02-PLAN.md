## Codebase Map Alignment

This plan adheres strictly to all 7 codebase map files in `.planning/codebase/`:
- **ARCHITECTURE.md**: Accounts for `load_ai_model()` memoization pattern, `AiModel.ask_a_question_from_pdf_stream` generator contract, and `LocalEmbedding.get_context`.
- **CONCERNS.md**: Directly tests the critical risks:
  - Risk 1 (Unhandled Groq API / startup failures): `test_local_llm.py` asserts missing `GROQ_API_KEY` raises `ValueError` with clear remediation text, and verifies behavior on mocked API errors.
  - Risk 2 (No persistence & per-session embedding models): Benchmarks RSS memory impact of loading `SentenceTransformer` in `scripts/benchmark_baseline.py`.
  - Risk 5 (Divergent retrieval queries & prompt injection vulnerability): Tests query formatting in `AiModel.ask_a_question_from_pdf_stream` (`last_user_msg + prompt`).
- **CONVENTIONS.md**: Follows standard 4-space indentation, `conftest.py` fixture naming, guard clause assertions, and import order (stdlib -> third-party -> local).
- **INTEGRATIONS.md**: Implements the exact mocking seams documented in `INTEGRATIONS.md:17-26` and `TESTING.md:48-57`:
  - `groq.Groq.chat.completions.create` stubbed with generator yielding canned chunks.
  - `sentence_transformers.SentenceTransformer.encode` stubbed with 384-dim normalized float32 vectors.
- **STACK.md**: Aligns with Python 3.11+ and dependencies in `requirements.txt`.
- **STRUCTURE.md**: Integrates into the root directory layout without disturbing existing entry points.
- **TESTING.md**: Directly implements the missing test suites (`test_local_embedding.py`, `test_local_llm.py`), `conftest.py`, and CI pipeline.
