## Codebase Map Alignment

This plan adheres strictly to all 7 codebase map files in `.planning/codebase/`:
- **ARCHITECTURE.md**: Validates standalone extraction behavior of `PdfReader` and pure-Python vector math of `VectorIndex`.
- **CONCERNS.md**: Directly tests and codifies existing known limitations:
  - Risk 2 (In-memory index with no persistence and linear scan): Captures baseline search behavior in `test_vector_index.py`.
  - Risk 3 (Unbounded file upload / unreadable PDFs): Generates `corrupt_invalid.pdf` and `scanned_sample.pdf` to test rejection and zero-chunk behavior in `test_pdf_reader.py`.
  - Risk 4 (Filename-keyed dedup): Codifies current chunking output for a 20-page document.
- **CONVENTIONS.md**: Follows 4-space indentation, `snake_case` test functions, top-level imports, section comment banners (`# ------------------------------------------------------------------`), and guard clause validation (`vector_index.py:77-84`).
- **INTEGRATIONS.md**: Tests `PdfReader` without external services; uses pure in-memory `BytesIO` streams.
- **STACK.md**: Uses existing Python 3.11+, `pypdf==5.3.0`, and `langchain-text-splitters==0.3.6`.
- **STRUCTURE.md**: Places all tests in a standard `tests/` root directory alongside existing root modules.
- **TESTING.md**: Implements the exact missing test suite recommended in `TESTING.md:27-34` (`tests/test_vector_index.py`, `tests/test_pdf_reader.py`).
