# Phase 7 Plan 07-02: Streamlit Cloud/Local Switch, Privacy Dialog & Egress Indicators

## Goal

Implement the Streamlit UI controls for toggling between Local and Cloud modes (`UI-04`), embed explicit privacy confirmation dialogs, support dynamic session credential configuration (Groq, OpenAI, Anthropic), render prominent cloud egress badges in both sidebar and chat interfaces, and guarantee that document ingestion, OCR, embeddings, and vector indexing remain 100% local (`INF-03`).

## Requirements covered

- **UI-04**: User can toggle between Local and Cloud modes with explicit warning and credential configuration dialogs.
- **INF-04**: System implements an optional `LiteLLMProvider` enabling cloud model routing (Groq, OpenAI, Anthropic) only when explicitly configured and consented to by user.

## Depends-on

- Plan 07-01 (`litellm_provider.py`, `AiModel` cloud mode support).
- Phase 1 UI state (`main.py`).
- Phase 4 persistent hybrid retrieval (`hybrid_retriever.py`).
- Phase 6 sidebar resource telemetry widget (`main.py`).

## Tracer Slice

Open Streamlit UI → sidebar displays `🔒 Local Privacy Mode (100% Offline)` → user clicks toggle to activate Cloud Mode → Streamlit displays confirmation dialog warning that document excerpts will be sent to external cloud APIs → user clicks "I Consent & Enable Cloud Mode" → selects provider (e.g. Groq / OpenAI / Anthropic) and enters API key for the session → model status updates to `☁️ Inference: Cloud [Groq: llama-3.3-70b]` → user submits question → document retrieval executes 100% locally on LanceDB → generation streams from cloud provider → response renders with an explicit cloud source attribution badge → toggling Cloud Mode OFF instantly reverts to local mode.

## Codebase Map Alignment

- **ARCHITECTURE.md**: Integrates Cloud Mode state into `st.session_state` (`cloud_mode`, `user_consented`, `cloud_provider_name`, `cloud_api_key`); wires `LiteLLMProvider` dynamically into `load_ai_model()`.
- **CONCERNS.md**:
  - Resolves **"Groq fallback exists with no opt-in, no egress signal"**: provides visible toggle, mandatory consent dialog, and transparent UI egress indicators.
  - Ensures local ingestion and vector search (`HybridRetriever`, `LocalEmbedding`) never perform outbound requests.
- **CONVENTIONS.md**:
  - Maintains `main.py` conventions and contracts.
  - Stores session API keys strictly in `st.session_state` without persisting secrets to unencrypted disk files.
- **INTEGRATIONS.md**: Connects Streamlit UI with `LiteLLMProvider` supporting Groq, OpenAI, and Anthropic.
- **STACK.md**: Uses existing Streamlit UI components (`st.toggle`, `st.dialog` / `st.expander`, `st.badge` / markdown captions).
- **STRUCTURE.md**: Updates `main.py` and creates `tests/test_cloud_privacy.py`.
- **TESTING.md**: Verifies privacy state machine, consent gating, and egress indicator contracts with 100% offline tests.

## Design Locks

- **D1 Default-Off Local Isolation:**
  - `st.session_state.cloud_mode = False` and `st.session_state.user_consented = False` on startup.
  - All operations default to local `llama-server` without outbound network calls.
- **D2 Mandatory Consent Gate:**
  - Enabling Cloud Mode requires explicit user confirmation of the data transmission notice.
  - If user cancels or dismisses, the toggle immediately resets to False.
- **D3 Ingestion Local-Only Invariant:**
  - PDF upload, text extraction (`DoclingReader`/`PdfReader`), conditional OCR (`RapidOCR`), dense embedding (`all-MiniLM-L6-v2` on CPU), and LanceDB hybrid indexing remain strictly on-device. No document bytes are ever sent to the cloud.
- **D4 Transparent Egress Badging:**
  - Sidebar status badge displays `☁️ Inference: Cloud ([Model])`.
  - Assistant responses generated in Cloud Mode display an unambiguous cloud disclaimer chip: `☁️ Generated via [Provider] ([Model]) with user consent`.

## Tasks

### Task 1 — Add Cloud Mode State & Consent Dialog to `main.py`
- **Files to touch:** `main.py`
- **What to do:**
  1. Initialize session keys: `cloud_mode: bool = False`, `user_consented: bool = False`, `cloud_provider: str = "groq"`, `cloud_model: str = "groq/llama-3.3-70b-versatile"`, `cloud_api_key: str = ""`.
  2. In sidebar, render a Cloud Mode section:
     - Toggle: "Enable Cloud Inference".
     - When user toggles ON without existing consent, present an explicit consent warning modal or confirmation panel explaining:
       - What is transmitted (only query and retrieved evidence text).
       - What remains local (document files, OCR images, embeddings, vector database).
     - Buttons: "I Understand & Consent", "Cancel (Keep Local)".
  3. When consented and enabled, render provider selector:
     - Options: Groq (`groq/llama-3.3-70b-versatile`), OpenAI (`openai/gpt-4o-mini`), Anthropic (`anthropic/claude-3-5-haiku-20241022`).
     - Password input for API key (resolves automatically if present in `.env` / `st.secrets`).
  4. Dynamically instantiate `LiteLLMProvider` with `user_consented=True` and attach to active `AiModel`.

### Task 2 — Render Egress Indicators in Sidebar & Chat Messages
- **Files to touch:** `main.py`
- **What to do:**
  1. Update sidebar model status indicator:
     - Local mode: `🟢 Inference: Local ([model])`
     - Cloud mode: `☁️ Inference: Cloud ([provider]: [model])`
     - Offline mode: `⚠️ Inference: Offline (setup required)`
  2. Update chat response rendering in `tab_chat`:
     - When answer is generated via cloud provider, append or display a distinctive egress notice:
       `st.caption("☁️ *Generated via external cloud provider ([model]) with user consent.*")`
  3. Ensure "Clear All" resets session cloud credentials if desired or retains explicit user consent.

### Task 3 — Author Privacy & UI Contract Tests in `tests/test_cloud_privacy.py`
- **Files to touch:** `tests/test_cloud_privacy.py` (new)
- **What to do:**
  1. Test consent state transitions: toggle without consent defaults to local; consent enables cloud provider.
  2. Test local-only ingestion invariant: verify that `PdfReader`, `LocalEmbedding`, and `HybridRetriever` perform zero network requests.
  3. Test egress indicator metadata in chat turn schema.
  4. Test dynamic provider switching (Groq -> OpenAI -> Anthropic).
