# Phase 6 Plan 06-01: Resource Profiling, Concurrency Gate & VRAM Benchmarks

## Goal

Implement the system resource telemetry module (`resource_telemetry.py`), enforce the single-active-LLM inference gate (`InferenceGate` in `local_llm.py`) to guarantee the 4 GB VRAM ceiling on the RTX 3050 Laptop GPU (`QUAL-01`), tune local `llama-server` runtime parameters, and author an automated benchmark script (`scripts/profile_resources.py`) that profiles cold/warm workloads and outputs `.planning/research/RESOURCE_PROFILE.json`.

## Requirements covered

- **QUAL-01**: System guarantees memory safety on 4 GB VRAM (RTX 3050 Laptop) by enforcing max one active LLM on GPU and cold/warm memory benchmarks.

## Depends-on

- Phase 2 inference pipeline (`local_llm.py`, `model_provider.py`, `llama_cpp_provider.py`).
- Phase 4 persistent hybrid retrieval (`hybrid_retriever.py`, `local_embedding.py`).
- Phase 5 grounded summarization and QA (`summarizer.py`, `citation_validator.py`).

## Tracer Slice

Trigger multi-page PDF ingestion and query → `InferenceGate` acquires exclusive execution lock ensuring zero parallel LLM calls → `resource_telemetry.py` monitors GPU VRAM via `nvidia-smi` and process RSS via `psutil` → latency tracker measures timing per pipeline stage → `scripts/profile_resources.py` executes end-to-end benchmark across cold and warm runs → outputs empirical data into `.planning/research/RESOURCE_PROFILE.json` demonstrating peak VRAM remains strictly below 3.8 GB.

## Design Locks

- **D1 Single-Active-LLM Concurrency Lock:**
  - Implemented as `InferenceGate` with a threading `Lock` and acquire timeout.
  - Wrapped around `AiModel.stream_text`, `AiModel.generate_text`, and `Summarizer.summarize_document`.
  - Guarantees strictly max 1 LLM process executes on the GPU at any instant (`QUAL-01`).
- **D2 Headless-Safe Telemetry:**
  - `get_gpu_memory_info()` queries `nvidia-smi` via stdlib `subprocess` with a 2-second timeout.
  - If `nvidia-smi` is unavailable (e.g. GitHub Actions CI runners, non-NVIDIA machines), returns `None` gracefully without throwing exceptions.
  - `get_process_memory_info()` uses `psutil` if available, returning RSS and VMS in MB.
- **D3 Automated Benchmark Artifact:**
  - Benchmark script `scripts/profile_resources.py` measures:
    1. Cold vs warm document ingestion latency and RAM delta.
    2. Cold vs warm summarization latency (verifying SQLite cache delivers < 50ms response).
    3. Hybrid retrieval latency under LanceDB.
    4. GPU VRAM baseline, peak, and headroom.
  - Serializes results to `.planning/research/RESOURCE_PROFILE.json`.

## Tasks

### Task 1 — Implement `resource_telemetry.py`
- **Files to touch:** `resource_telemetry.py` (new, repo root)
- **What to do:**
  - Implement `get_gpu_memory_info() -> dict[str, float] | None`:
    - Executes `nvidia-smi --query-gpu=memory.total,memory.used,memory.free --format=csv,noheader,nounits`.
    - Returns `{"total_mb": float, "used_mb": float, "free_mb": float, "utilization_pct": float}`.
    - Catches `(FileNotFoundError, subprocess.SubprocessError, Exception)` and returns `None`.
  - Implement `get_process_memory_info() -> dict[str, float]`:
    - Queries `psutil.Process().memory_info()`.
    - Returns `{"rss_mb": float, "vms_mb": float}`.
    - Gracefully defaults to zeros if `psutil` is unavailable.
  - Implement `LatencyTracker(stage_name: str)` context manager:
    - Measures wall-clock execution time via `time.perf_counter()`.
    - Records start/end timestamps and elapsed milliseconds.
- **Test command:** `pytest tests/test_resource_telemetry.py -v`
- **Commit message:** `feat(06): implement resource_telemetry module with GPU, RAM, and latency profiling`
