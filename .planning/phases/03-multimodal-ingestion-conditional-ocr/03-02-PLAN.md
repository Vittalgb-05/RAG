# Phase 3 Plan 03-02: Conditional RapidOCR Fallback for Scanned Pages

## Goal

Implement conditional local OCR via RapidOCR (`ocr_fallback.py`) that triggers exclusively on pages with missing or unextractable text (< 50 characters), bypassing clean digital pages to maintain sub-5-second throughput, and isolating OCR errors at the page level.

## Requirements covered

- **INGEST-04**: System conditionally invokes local RapidOCR on pages with missing or unextractable text (< 50 characters) while bypassing OCR on clean digital pages.

## Depends-on

- Phase 3 Plan 03-01 (`docling_reader.py`, `models.py`).
- Phase 1 canonical models and storage (`models.py`, `doc_store.py`).

## Tracer Slice

Process `scanned_sample.pdf` (0 extractable text characters) → verify `should_ocr_page` evaluates to `True` → invoke mock RapidOCR engine returning simulated text → verify output chunks carry `extraction="ocr"` → process `clean_digital.pdf` (20 pages) → verify OCR engine is never called (0 invocations).

## Codebase Map Alignment

- **ARCHITECTURE.md**: Placed in the ingestion layer as a conditional fallback stage following primary text extraction.
- **CONCERNS.md**:
  - Mitigates **"OCR / visual ingestion for scanned documents"**: Directly resolves the gap where image-only pages produced zero chunks.
  - Mitigates **"Fault-isolation scope too narrow"**: Implements per-page try/except around OCR rendering and recognition.
- **CONVENTIONS.md**:
  - Flat module at repo root (`ocr_fallback.py`).
  - Optional-import guard (`try: from rapidocr_onnxruntime import RapidOCR ... except ImportError: ...`).
  - Pure CPU execution without GPU/VRAM contention.
- **INTEGRATIONS.md**: Runs RapidOCR CPU-only via ONNX Runtime without external network access.
- **STACK.md**: Adds `rapidocr-onnxruntime>=1.3.0` to `requirements.txt`.
- **STRUCTURE.md**: Places module in `ocr_fallback.py` and tests in `tests/test_ocr_fallback.py`.
- **TESTING.md**: Uses `scanned_sample.pdf` and `clean_digital.pdf` from the synthetic corpus, with mock engine fixtures for 100% offline verification in CI.

## Design Locks

- **D1 50-character threshold:** OCR is triggered if and only if a page's extracted text length is `< 50` characters or page status is `"empty"`.
- **D2 Clean-page bypass:** Pages with `char_count >= 50` must completely bypass the OCR pipeline, avoiding rendering and inference overhead.
- **D3 CPU ONNX execution:** RapidOCR is restricted to CPU execution providers to preserve 100% of GPU VRAM for the VLM.
- **D4 Provenance tagging:** All chunks derived from OCR text must have `extraction="ocr"`.
- **D5 Page-level fault isolation:** Exceptions during page rendering or OCR recognition must mark that individual page as `Page(status="failed", error=...)` and never abort document ingestion.

### Task 2 — Implement `ocr_fallback.py`
- **Files to touch:** `ocr_fallback.py` (new, repo root)
- **What to do:**
  - Implement `should_ocr_page(text: str, status: str = "ok", threshold: int = 50) -> bool`.
  - Implement `OcrEngine`:
    - Optional-import guard for `rapidocr_onnxruntime` and page image renderers (`pymupdf` / `pypdfium2` / `pdf2image`).
    - Lazy singleton for `RapidOCR` instance.
    - `ocr_page_image(image_bytes_or_array) -> tuple[str, float]`: runs OCR, returns extracted text and confidence score.
  - Implement `apply_conditional_ocr(pdf_bytes, page_records, existing_chunks, doc_id, sha12) -> tuple[list[Page], list[Chunk]]`:
    - Scans pages where `should_ocr_page` is `True`.
    - Renders page image and runs OCR within a per-page try/except block.
    - Emits new `Chunk` records with `extraction="ocr"`.
    - Updates `Page` records with new `char_count`, `status="ok"`, and `num_chunks`.
- **Test command:** `pytest tests/test_ocr_fallback.py -v` (Task 3)
