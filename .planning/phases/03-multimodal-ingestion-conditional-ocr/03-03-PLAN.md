# Phase 3 Plan 03-03: Visual Element Detection, Cropping & VLM Analysis with Provenance Isolation

## Goal

Implement visual element detection and high-fidelity cropping (`visual_analyzer.py`), query the local VLM (`BaseModelProvider.analyze_image`) for structured visual descriptions, store descriptions as `EvidenceElement` records with explicit model provenance without contaminating ground-truth table data, add SQLite persistence for evidence elements, and wire the multimodal pipeline into `main.py`.

## Requirements covered

- **VIS-01**: System identifies visual elements (charts, diagrams, flowcharts, figures, visual tables) and renders high-fidelity image crops using PyMuPDF/Pillow.
- **VIS-02**: System queries local VLM with targeted prompts to generate structured visual descriptions for detected visual elements.
- **VIS-03**: System stores visual descriptions as distinct derived artifacts tagged with model and version provenance, preventing ungrounded visual approximations from contaminating ground-truth table data.

## Depends-on

- Phase 2 local inference provider (`model_provider.py`, `llama_cpp_provider.py`).
- Phase 3 Plan 03-01 (`docling_reader.py`) and Plan 03-02 (`ocr_fallback.py`).
- Phase 1 canonical models and storage (`models.py`, `doc_store.py`).

## Tracer Slice

Process `chart_diagram.pdf` (vector diagram without raster images) → detect visual diagram region → render 2x zoom PNG crop → query `mock_llama_provider.analyze_image` with targeted diagram prompt → produce `EvidenceElement(kind="chart", source="vlm:qwen3-vl-2b")` → verify `EvidenceElement` is stored in SQLite `evidence_elements` table → verify table text in `dense_table.pdf` remains strictly `source="docling"` without VLM overwrite.

## Design Locks

- **D1 Vector and raster detection:** Detect embedded raster images via image xrefs/blocks and vector diagrams via vector drawing primitive density (`get_drawings`), ensuring vector charts (like `chart_diagram.pdf`) are detected.
- **D2 High-resolution cropping:** Render crops at 2x matrix zoom (`Matrix(2.0, 2.0)`) to PNG bytes to preserve text and diagram legibility for the 2B VLM.
- **D3 Graceful vision degradation:** If the active provider does not support vision (e.g. Groq Cloud text fallback), retain the visual crop, set `content="[Visual element: vision analysis unsupported by active model]"`, and continue without failing the document.
- **D4 Provenance separation (VIS-03):** Visual descriptions must be stored as `EvidenceElement` instances tagged with `source=f"vlm:{model_name}"` and must never overwrite or merge into ground-truth table text (`source="docling"`).
- **D5 Database migration (MIGRATIONS[2]):** Add `evidence_elements` table to `DocStore` with foreign key cascade to `documents(doc_id)`.
