# Phase 5 Plan 05-02: Grounded QA Prompt Pipeline, Streaming Generation & Automated Citation Validator

## Goal

Implement the evidence-grounded QA prompt pipeline with explicit numbered citations (`[E1]`, `[E2]`), XML injection isolation, token-by-token streaming response generation, automated citation verification enforcing $\ge 95\%$ citation precision, and explicit abstention detection for unanswerable queries (QA-01, QA-02, QA-03, QA-04).

## Requirements covered

- **QA-01**: User can ask natural-language questions and receive answers streamed live into the chat interface grounded in retrieved document evidence.
- **QA-02**: System formats prompts with explicit numbered evidence identifiers (`[E1]`, `[E2]`) and strict boundaries preventing prompt injection from document text.
- **QA-03**: System validates all generated citations against retrieved evidence records, enforcing a minimum 95% citation precision.
- **QA-04**: System detects unanswerable queries and explicitly abstains ("The document does not contain sufficient evidence") without inventing citations.

## Depends-on

- Plan 04-02 (`models.py`, `RetrievalResult`, `EvidenceSnippet`, shared retrieval contract RETR-04).
- Phase 2 local inference pipeline (`prompt_budget.py`, `local_llm.py`, `model_provider.py`).

## Tracer Slice

Retrieve top-k evidence snippets using `HybridRetriever.search_hybrid` → format prompt with `<document_context>` XML boundaries and numbered evidence blocks (`[E1] (doc, p. 1)`) → stream answer through `AiModel.ask_a_question_from_pdf_stream` → parse generated tokens for citation references (`[E1]`) → run `CitationValidator.validate_citations` → assert citation precision is $\ge 0.95$ → query unanswerable prompt → verify model or validator emits explicit abstention statement with zero hallucinated citations.

## Design Locks

- **D1 Grounding Prompt Structure (`QA-02`):**
  - Prompt requires the model to support every factual assertion with bracketed citation identifiers matching the numbered snippets (`[E1]`, `[E2]`).
  - Context is enclosed in `<document_context>` tags. All text inside context is sanitized via `sanitize_xml_boundary`.
  - Explicit directive: If evidence is insufficient, state: "The document does not contain sufficient evidence to answer this question."
- **D2 Automated Citation Precision Metric (`QA-03`):**
  - Regex extractor matches `\[E(\d+)\]`.
  - A citation `[Ek]` is valid if and only if $1 \le k \le len(retrieval\_result.snippets)$.
  - Precision formula:
    $$\text{Precision} = \begin{cases} 
    1.0 & \text{if abstention detected with 0 citations} \\
    \frac{|\text{Valid Citations}|}{|\text{Total Unique Citations Claimed}|} & \text{if citations present} \\
    0.0 & \text{if ungrounded factual response with 0 citations}
    \end{cases}$$
  - Pass condition: $\text{Precision} \ge 0.95$.
- **D3 Explicit Abstention Detection (`QA-04`):**
  - Identifies canonical abstention markers:
    - `"The document does not contain sufficient evidence"`
    - `"The document does not contain information on this topic"`
    - `"Insufficient information in the provided context"`
  - Validates that an abstaining response does NOT contain fabricated evidence citations. If citations are present in an abstention, it is flagged as invalid.
