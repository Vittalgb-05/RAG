# Phase 5 Plan 05-03: Streamlit UI Enhancement — Summary Profile Selector & Interactive Evidence Drawer

## Goal

Enhance the Streamlit user interface in `main.py` with a dedicated Document Summarizer interface supporting 5 summary profiles and expandable source page references (UI-02), alongside an interactive chat evidence drawer displaying clickable source chips, exact cited snippet excerpts, page numbers, and automated citation precision metrics (UI-03).

## Requirements covered

- **UI-02**: User can select summary profiles and view formatted markdown summaries with expandable source page references.
- **UI-03**: User can view interactive evidence chips and drawer alongside chat answers showing the exact cited text and page number.

## Depends-on

- Plan 05-01 (`summarizer.py`, `SummaryProfile`, `SummaryResult`, `DocStore` v3 summary caching).
- Plan 05-02 (`citation_validator.py`, `CitationVerificationResult`, grounded QA prompt pipeline).
- Plan 04-02 (`models.py`, `RetrievalResult`, `EvidenceSnippet`, shared retrieval contract RETR-04).

## Tracer Slice

Open Streamlit UI → navigate to "📑 Document Summarizer" tab → select indexed PDF and choose "Study Notes" profile → click "Generate Summary" → view formatted markdown summary with an expandable "📄 Referenced Source Pages" drawer → switch to "💬 Ask Your Document" tab → submit a question → observe token-by-token streaming → inspect assistant turn rendering with source chips (`[E1] (p. 2)`) → expand "🔍 Cited Evidence & Source Context" drawer → verify exact quote snippet, page number, retrieval score, and citation precision badge (`✅ 100% Verified`).

## Codebase Map Alignment

- **ARCHITECTURE.md**: Enhances the Presentation / Orchestration layer in `main.py`. Unifies UI consumption of `RetrievalResult`, `Summarizer`, and `CitationValidator`.
- **CONCERNS.md**:
  - Mitigates **"Unguarded st.write_stream crashes"**: Retains comprehensive `try/except Exception` around streaming and validates citations cleanly on the aggregated response text.
  - Mitigates **"Redundant dual-query divergence"**: Passes the single shared `RetrievalResult` into the citation validator and stores snippet context directly in chat turn session state.
  - Mitigates **"Clear All resets session but not persistent stores"**: Ensures summary state and cache selections reset gracefully on Clear All without breaking underlying SQLite integrity.
- **CONVENTIONS.md**:
  - Clean Streamlit idioms: Tabs (`st.tabs`), Expanders (`st.expander`), Status containers (`st.status`), Badges/Pills (`st.badge` / markdown pills).
  - Preserves responsive layout and mobile/desktop readability.
- **INTEGRATIONS.md**: Pure local Streamlit rendering; zero external front-end libraries or client-side JavaScript required.
- **STACK.md**: Streamlit 1.42.0.
- **STRUCTURE.md**: Edits `main.py` and adds UI integration tests in `tests/test_main_ui.py` or updates `tests/test_local_llm.py`.
- **TESTING.md**: Verifies UI data flow, state serialization, and evidence drawer rendering contracts using headless/mocked test cases.

## Design Locks

- **D1 Tabbed Presentation Structure:**
  - `tab_chat, tab_summary = st.tabs(["💬 Ask Your Document", "📑 Document Summarizer"])`
  - Keeps chat and document-level analytical summarization cleanly separated while sharing the same underlying indexed document state.
- **D2 Summary Profile Selector & Page Reference Drawer (`UI-02`):**
  - Document selector: Dropdown selecting from `st.session_state.indexed_files`.
  - Profile selector: Radio / segmented control with 5 profiles (`Overview`, `Detailed`, `Study Notes`, `Tables & Figures`, `Findings`).
  - Generate button: Calls `Summarizer.summarize_document(...)`.
  - Cache indication: Highlights whether the summary was retrieved from persistent cache (`⚡ Cached`) or generated fresh.
  - Expandable drawer: `with st.expander("📄 Referenced Source Pages", expanded=False):` lists all cited pages and summary metadata.
- **D3 Interactive Evidence Chips & Citation Drawer (`UI-03`):**
  - Assistant chat turns store both `content`, `retrieval_result`, and `citation_verification` in `st.session_state.chat_history`.
  - For each assistant turn, renders:
    1. Formatted answer markdown.
    2. Precision badge: `✅ Verified Grounding (100% precision)` or `⚠️ Abstention / Missing Citations`.
    3. Source chips: `[E1] document.pdf (p. 2)`.
    4. Expandable citation drawer: `with st.expander("🔍 Cited Evidence & Source Context", expanded=False):`
       - Displays each cited snippet with rank header, page number, relevance score, and full excerpt blockquote.

### Task 2 — Implement interactive evidence drawer and precision badges in `main.py` chat loop
- **Files to touch:** `main.py`
- **What to do:**
  - In `tab_chat` and chat history replay:
    - Update `st.session_state.chat_history` turn schema to store `verification_result` and `cited_snippets`.
    - On answer generation completion:
      - Call `citation_validator.validate_citations(full_response, retrieval_res)`.
      - Store validation result and snippets in message turn.
    - In chat replay and live assistant message block:
      - Render citation precision badge:
        - If valid: `st.caption("✅ Grounded (XX% precision)")` or green pill.
        - If abstention: `st.caption("ℹ️ Document abstention (no evidence found)")`.
        - If low precision: `st.caption("⚠️ Unverified citations detected")`.
      - Render interactive source chips.
      - Render `st.expander("🔍 Cited Evidence & Source Context", expanded=False)`:
        - For each cited snippet: show `[E{rank}] {filename} (p. {page})`, score, and quoted text excerpt.
