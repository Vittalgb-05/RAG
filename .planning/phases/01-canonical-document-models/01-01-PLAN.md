# Phase 1 Plan 01-01: Canonical Pydantic Schemas + SQLite Metadata Store

## Goal

Replace untyped chunk dicts (`{content, filename, page, chunk_id}` in `pdf_reader.py:48-56`)
and volatile session-only metadata (`indexed_files`, `document_metadata` in `main.py:44-51`)
with typed Pydantic v2 canonical models and an ACID SQLite store that persists across
restarts — while keeping `VectorIndex`, `LocalEmbedding.build_index`, and `main.py`
working unchanged via `model_dump()` key-compatibility.

## Requirements covered

- **STORE-02**: Typed Pydantic canonical models (`Document`, `Page`, `EvidenceElement`,
  `Chunk`) with explicit bounding-box coordinates and source extraction metadata.
- **STORE-01**: SQLite store persisting document metadata, processing status, page counts,
  extraction logs (partial — full UI/restart proof completes in 01-02 wiring; this plan
  delivers the store + its own persistence tests).
- **STORE-03**: Disk-cache layout keyed by SHA-256 + config version (schema + `CONFIG_VERSION`
  constant + cache-path helper; cache read/write wiring completes in 01-02).

## Depends-on

- Phase 0 corpus + test harness (`tests/conftest.py` seams, `clean_digital.pdf`,
  `corrupt_invalid.pdf`, `pyproject.toml` pytest/ruff config). No plan dependency
  inside Phase 1 — this is the tracer-leading plan.

## Tracer slice (build first, before expansion tasks)

Thin production-quality path proving the contract end-to-end: construct a `Chunk` from
real `PdfReader.get_paragraphs()` output on `clean_digital.pdf` → `model_dump()` equals
legacy keys → insert parent `Document` row into a `tmp_path` SQLite DB via `DocStore` →
read it back. This is Task 2's test (`test_tracer_chunk_to_store_roundtrip`);
Tasks 1–3 must land in order before Tasks 4–7 expand outward.

## Design locks (from RESEARCH.md §2 — follow unless a factual error is found)

- **D1 Pydantic v2-native only** (`BaseModel` + `Field`, `@field_validator`,
  `model_dump()`/`model_dump_json()`/`model_validate()`; never `dict()`/`.parse_obj`/`class Config`).
  `frozen=True` on `BBox`/`Chunk`; mutable `Document`; `extra="forbid"` on
  `Document`/`Chunk`. If installed pydantic is v1 at execution time, stop and surface —
  do not shim.
- **D2 sqlite3 stdlib only.** Reject SQLAlchemy/aiosqlite. Per-operation
  connect → execute → commit → close inside a context manager; never cache a connection
  in `st.session_state` or `@st.cache_resource`. `PRAGMA journal_mode=WAL` +
  `busy_timeout=5000` at connect. `PRAGMA user_version = 1` + `_migrations` map.
- **D3 schema shapes** exactly per RESEARCH.md §D3 (field names/types below are normative):
  `BBox{x0,y0,x1,y1,page_width?,page_height?}`, `Chunk{content(min_length=1),filename,
  page(ge=1),chunk_id,doc_id,char_start?,char_end?,bbox?=None,extraction="pypdf",
  embedding_model?=None}`, `Page{doc_id,page_num(ge=1),status, char_count,error?,num_chunks}`,
  `EvidenceElement{element_id,doc_id,page(ge=1),kind="text",content,bbox?=None,source="pypdf"}`,
  `Document{doc_id,filename,sha256(/^[0-9a-f]{64}$/),size_bytes(ge=0),num_pages(ge=0),
  status,upload_time,num_chunks}`. SQLite mirrors 1:1 with nullable forward-compat
  columns `chunks.bbox_json TEXT NULL`, `chunks.embedding_model TEXT NULL`.
- **D4/D5**: `doc_id = "doc_" + sha256[:16]`; `chunk_id = "{sha12}_p{page}_{j}"`;
  `CONFIG_VERSION = "chunker-1000-200-pypdf"`; cache layout
  `.cache/{sha256}/{config_version}/{pages.json,chunks.json,manifest.json}` via `pathlib`.
- Only new dependency line: `pydantic==2.11.9` in `requirements.txt`. No new secrets.

## Task 3 — `doc_store.py`: sqlite3-backed `DocStore` (per-op connections, WAL, migrations)

- **Files to touch:** `doc_store.py` (new, repo root).
- **What to do:**
  1. Top-of-file `"""..."""` summary + Google-style docstrings. Stdlib imports only
     (`sqlite3`, `json`, `pathlib`, `datetime` as needed) at top level.
  2. `class DocStore:` single public class, `__init__(self, db_path)` storing only the
     path (never a connection). Private `_connect()` helper opening
     `sqlite3.connect(db_path, timeout=5.0)` + `PRAGMA journal_mode=WAL` +
     `PRAGMA busy_timeout=5000` + `row_factory = sqlite3.Row`, then applying
     `_migrations` map keyed by `PRAGMA user_version`. Every public method:
     `with self._connect() as conn:` → execute → `conn.commit()` → close on exit.
     Explicitly comment why (R1: Streamlit reruns + Windows file locking forbid cached
     connections; R2: `check_same_thread` — forbid `@st.cache_resource` on the store).
  3. Schema v1 DDL (`CREATE TABLE IF NOT EXISTS`, `PRAGMA user_version = 1`):
     `documents(doc_id TEXT PRIMARY KEY, filename TEXT NOT NULL, sha256 TEXT NOT NULL
     UNIQUE, size_bytes INTEGER NOT NULL, num_pages INTEGER NOT NULL, status TEXT NOT NULL,
     upload_time TEXT NOT NULL, num_chunks INTEGER NOT NULL DEFAULT 0)`,
     `pages(doc_id TEXT NOT NULL, page_num INTEGER NOT NULL, status TEXT NOT NULL,
     char_count INTEGER NOT NULL DEFAULT 0, error TEXT, num_chunks INTEGER NOT NULL
     DEFAULT 0, PRIMARY KEY (doc_id, page_num))`,
     `chunks(chunk_id TEXT PRIMARY KEY, doc_id TEXT NOT NULL, filename TEXT NOT NULL,
     page INTEGER NOT NULL, content TEXT NOT NULL, char_start INTEGER, char_end INTEGER,
     bbox_json TEXT NULL, extraction TEXT NOT NULL DEFAULT 'pypdf',
     embedding_model TEXT NULL)`.
     `_migrations = {1: [DDL...]}`; on open, `if stored_version < 1: apply`.
  4. Public API (all keyword-friendly, all validate-then-write per `vector_index.py`
     guard style — `TypeError`/`ValueError` before mutating):
     `upsert_document(doc: Document) -> None` (UPSERT on `doc_id`, UNIQUE on `sha256`
     surfaces `sqlite3.IntegrityError` — do not swallow; caller maps to dedup-hit),
     `get_by_sha(sha256: str) -> Document | None`,
     `get_document(doc_id: str) -> Document | None`,
     `record_page(page: Page) -> None` (UPSERT on `(doc_id, page_num)`),
     `record_chunks(chunks: list[Chunk]) -> None` (executemany, single transaction),
     `list_documents() -> list[Document]`. Return Pydantic objects (validate on read via
     `model_validate(dict(row))`), accept Pydantic objects on write (`model_dump()`).
  5. Lifecycle `print()` diagnostics with `[DocStore]` prefix for open/migrate/write
     (match `[LocalEmbedding]` convention); never `st.*` inside this module.
- **Test command:** `pytest tests/test_doc_store.py tests/test_models.py -v` (store tests
