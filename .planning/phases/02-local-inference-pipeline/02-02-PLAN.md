## Design Locks

- **D1 Bounded context window:** Total context window locked to 4,096 tokens. Input budget capped at 3,072 tokens to guarantee at least 1,024 tokens for generation.
- **D2 History truncation policy:** When input budget is exceeded, truncate conversation history oldest-first while retaining the latest user question and retrieved evidence chunks.
- **D3 XML injection boundary:** Wrap all retrieved document text in `<document_context>` tags with explicit system instructions prohibiting obedience to instructions found inside the document text.
- **D4 Non-crashing startup:** If neither local `llama-server` nor Groq is available, `AiModel` initializes in `degraded` state with clear diagnostic guidance rather than raising an uncaught exception.
- **D5 Streamlit UI status banner:** The sidebar renders real-time inference status:
  - Local active: `🟢 Inference: Local (qwen3-vl-2b)`
  - Cloud active: `🔵 Inference: Groq Cloud (openai/gpt-oss-20b)`
  - Offline / Unreachable: `⚠️ Inference: Local llama-server offline (setup required)` with expandable command guide.
