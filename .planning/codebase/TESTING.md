## Test File Organization

**Location:**
- Separate `tests/` directory at the repository root; tests are **not** co-located with source.
- Flat layout: one file per production module or feature cluster. No subpackages under `tests/` other than `tests/data/corpus/`.
- `tests/conftest.py` holds the only shared fixtures.
- Synthetic assets: `tests/data/corpus/` contains `clean_digital.pdf`, `multi_column.pdf`, `dense_table.pdf`, `scanned_sample.pdf`, `chart_diagram.pdf`, `corrupt_invalid.pdf`, generated by `tests/data/corpus/generate_corpus.py`.

**Naming:**
- Files: `test_<module>.py` (`test_doc_store.py`, `test_hybrid_retriever.py`, `test_llama_cpp_provider.py`) or `test_<feature>.py` for cross-cutting behavior (`test_cloud_privacy.py`, `test_concurrency_lock.py`, `test_ui_smoke.py`, `test_cache_invalidation.py`).
- Functions: `test_<behavior>_<condition>` in snake_case, often suffixed with the requirement ID: `test_two_instance_interleave_R1`, `test_summary_get_with_model_version_invalidation`, `test_capabilities`, `test_generate_text_http_error`.
- Helper functions and mock providers are module-level and prefixed `_` or `Mock`: `_make_unit_vector` (`tests/test_hybrid_retriever.py:12`), `MockVisionProvider`, `MockTextOnlyProvider` (`tests/test_visual_analyzer.py:19`, `58`), `MockSummarizerProvider` (`tests/test_summarizer.py:16`), `DummyProvider` (`tests/test_concurrency_lock.py:13`).
- Shared fixture names describe the seam, not the technology: `mock_llama_provider`, `mock_sentence_transformer`, `mock_groq_client`, `sample_pdf_path`.

## Test Structure

**Suite Organization:**
Most files open with a module docstring (or banner comment) that names the module under test and lists the invariants covered, then imports, then a flat list of test functions. Classes are used only for mock implementations, never for grouping tests.

```python
# tests/test_doc_store.py:1-17
# ------------------------------------------------------------------
# Unit Tests for DocStore (doc_store.py)
# Verifies SQLite persistence, WAL mode, migrations, UNIQUE(sha256)
# constraint handling, page failure tracking, and chunk storage.
# ------------------------------------------------------------------

from pathlib import Path
import sqlite3
import pytest
from doc_store import DocStore
from models import BBox, Chunk, Document, EvidenceElement, Page, SummaryResult


def test_insert_get_roundtrip(tmp_path):
    """Verify Document insertion and retrieval equality."""
    db_file = tmp_path / "test_docs.db"
    store = DocStore(db_file)
    ...
```

**Patterns:**
- **Arrange → Act → Assert within one function**, separated by blank lines; comments label multi-step scenarios (`# 1. Start in local mode`, `# 2. Attempting cloud provider without consent ...`) in `tests/test_cloud_privacy.py:24-52`.
- **Every test has a one-line docstring** stating the behavior being verified. Newer files also annotate `-> None` (`tests/test_llama_cpp_provider.py:11`, `tests/test_cloud_privacy.py:13`); older files omit annotations.
- **Fresh state per test**: `tmp_path` for every SQLite file and LanceDB directory; no shared temp database. Example: `db_file = tmp_path / "test_docs.db"` (`tests/test_doc_store.py:16`).
- **Autouse fixtures reset process-global state** rather than relying on test order:
  - `tests/test_ui_smoke.py:19-35` clears `st.session_state` and re-seeds every key used by UI code.
  - `tests/test_concurrency_lock.py:61-68` drains `InferenceGate` before and after each test.
  - `tests/test_resource_telemetry.py:25-32` clears latency history and GPU cache around each test.
  - `tests/test_hydration.py:12-20` resets session state for hydration tests.
- **Direct assertion of error type and message fragment**: `with pytest.raises(sqlite3.IntegrityError):` (`tests/test_doc_store.py:66`), `with pytest.raises(PermissionError, match="Cloud transmission blocked"):` (`tests/test_cloud_privacy.py:34`), `with pytest.raises(RuntimeError, match="llama-server generation failed"):` (`tests/test_llama_cpp_provider.py:128`).
- **Negative assertions are explicit**: `assert not InferenceGate.is_locked()`, `mock_recognizer.assert_not_called()`, `assert "http://" not in stripped`.
- **Round-trip tests** are the default for models and persistence: write → read → equality (`tests/test_doc_store.py:14-38`, `tests/test_models.py:102-117`).

## Mocking

**Framework:** stdlib `unittest.mock` (`MagicMock`, `patch`) plus pytest's `monkeypatch`. No `pytest-mock`, no `responses`, no `vcrpy`.

**Patterns:**

1. **Transport-level mocks for HTTP** (preferred for provider tests):
```python
# tests/test_llama_cpp_provider.py:27-40
def test_health_check_healthy() -> None:
    """Test check_health when llama-server responds 200 OK."""

    def handler(request: httpx.Request) -> httpx.Response:
        assert request.url.path == "/health"
        return httpx.Response(200, json={"status": "ok"})

    transport = httpx.MockTransport(handler)
    provider = LlamaCppProvider(transport=transport)
    status = provider.check_health()
    assert status.status == "healthy"
    ...
    provider.close()
```
Handlers also raise transport errors (`raise httpx.ConnectError("Connection refused", request=request)`, `tests/test_llama_cpp_provider.py:62`) and capture request bodies for assertion (`captured_payload = json.loads(request.read())`, line 94). `httpx.MockTransport` is the correct seam for any new HTTP integration.

2. **Full-class mock providers implementing `BaseModelProvider`** when behavior (call recording, streaming, vision support) matters:
```python
# tests/test_visual_analyzer.py:19-36
class MockVisionProvider(BaseModelProvider):
    """Mock local provider with vision support for offline tests."""

    def __init__(self, model_name: str = "qwen3-vl-2b"):
        self._model_name = model_name
        self.analyze_calls: list[dict] = []

    def get_capabilities(self) -> ProviderCapabilities:
        return ProviderCapabilities(
            model_name=self._model_name,
            context_window=4096,
            supports_vision=True,
            is_local=True,
            supports_streaming=True,
        )
```
See also `MockTextOnlyProvider` (`tests/test_visual_analyzer.py:58`) for the no-vision branch, `MockSummarizerProvider` (`tests/test_summarizer.py:16`) which pattern-matches prompt templates, and `DummyProvider` (`tests/test_concurrency_lock.py:13`) which sleeps to exercise concurrency.

3. **Module-attribute monkeypatching for optional dependencies**:
```python
# tests/test_hybrid_retriever.py:156-158
def test_hybrid_retriever_fallback_when_lancedb_missing(tmp_path, monkeypatch):
    monkeypatch.setattr("hybrid_retriever.lancedb", None)
```
Also `monkeypatch.setattr(local_embedding, "SentenceTransformer", ...)` (`tests/conftest.py:91`) and `monkeypatch.setattr(socket, "create_connection", guarded_create_connection)` to prove zero egress (`tests/test_cloud_privacy.py:64`).

4. **`patch()` for module-level symbols and OS boundaries**:
```python
# tests/test_hydration.py:40-49
with patch("ui.hydration.HybridRetriever") as mock_retriever_cls:
    mock_instance = MagicMock()
    mock_instance.count_chunks.return_value = 5
    mock_retriever_cls.return_value = mock_instance
    with patch("ui.hydration.LocalEmbedding") as mock_embed_cls:
        mock_embed_cls.return_value = MagicMock()
        hydrate_startup_state(store)
```
Also `patch("subprocess.run")` (`tests/test_start_launcher.py:93`), `patch("start.REPO_ROOT", tmp_path)` (line 30), `patch("urllib.request.urlopen", ...)` (line 68), and `patch.object(sys, "version_info", (3, 11, 2))` (line 21). Patch the symbol **where it is looked up** (`ui.hydration.HybridRetriever`), not where it is defined.

5. **Manual save/restore for class-level attributes** when `monkeypatch` is not injected:
```python
# tests/test_hybrid_retriever.py:27-36
original_st = local_embedding.SentenceTransformer
try:
    local_embedding.clear_shared_model_cache()
    local_embedding.SentenceTransformer = mock_st_class
    ...
finally:
    local_embedding.clear_shared_model_cache()
    local_embedding.SentenceTransformer = original_st
```

**What to Mock:**
- Network calls (`httpx.MockTransport`, `patch("urllib.request.urlopen")`, `patch("subprocess.run")`).
- Native/model downloads (`SentenceTransformer`, `Groq` client, `lancedb`, Docling converter).
- Streamlit session state when the real runtime is unavailable (`monkeypatch.setattr(st, "session_state", fake_state, raising=False)`, `tests/test_cloud_privacy.py:242`).
- Clock/latency-sensitive state (`clear_gpu_cache`, `clear_latency_history`).

**What NOT to Mock:**
- Pydantic models, `DocStore`, and `VectorIndex` — tests use real instances against `tmp_path` to verify SQL and persistence behavior.
- The synthetic PDF corpus — extraction tests read the real generated PDFs (`tests/test_pdf_reader.py`, `tests/test_ocr_fallback.py`, `tests/test_visual_analyzer.py`) so layout/OCR paths are genuinely exercised.
- `InferenceGate` locking semantics — tested with real threads, not mocks (`tests/test_concurrency_lock.py:99-110`).

## Test Types

**Unit Tests:**
- Dominant type. Pure functions and Pydantic validation are tested directly: `test_rrf_scoring_math` (`tests/test_hybrid_retriever.py:176`), `test_extract_page_references` (`tests/test_summarizer.py:93`), the schema suite in `tests/test_models.py`, and sanitizer cases in `tests/test_sanitizer.py`.
- Persistence tests use real SQLite files in `tmp_path` (`tests/test_doc_store.py`).

**Integration Tests:**
- Service-level tests wire real `DocStore` + real `HybridRetriever` + real `LocalEmbedding` (CPU-pinned) while mocking only the network: `tests/test_hybrid_retriever.py`, `tests/test_cloud_privacy.py:55-102`.
- End-to-end privacy invariant: all outbound sockets are replaced with a raising stub during ingestion/embedding/search (`tests/test_cloud_privacy.py:61-64`).
- UI orchestration: `tests/test_main_ui.py` exercises `IngestionService` and `LifecycleService` against a `tmp_path` database and vector store (`lines 337-513`), while `tests/test_ui_smoke.py` covers component markup, session-state reset, and hydration.

**E2E Tests:**
- No browser/Streamlit E2E harness. `tests/test_ui_smoke.py` is a server-side smoke suite that imports `main` and inspects session state and generated HTML strings; it does not launch a Streamlit server.
- No GPU/VLM execution in tests. All vision/inference is mocked; `tests/test_local_embedding.py` verifies CPU pinning without downloading weights.

**Test Doubles for Concurrency and Privacy:**
- Real threads for lock semantics, with a drain fixture: `tests/test_concurrency_lock.py:61-110`.
- `monkeypatch.setattr(InferenceGate, "acquire", MagicMock(return_value=False))` to simulate a busy gate and assert the user-facing warning (`tests/test_concurrency_lock.py:190-195`).

## Common Patterns

**Async / Streaming Testing:**
- Streaming APIs are synchronous generators; tests consume them with `list(...)` or `"".join(...)`:
  ```python
  tokens = list(provider.stream_text("prompt"))
  assert "".join(tokens) == "This is a grounded answer."
  ```
  `mock_llama_provider` exposes `stream_calls` so tests can assert the exact prompt/history/max_tokens passed (`tests/conftest.py:144-162`).
- No `pytest-asyncio`; there are no `async def` tests.

**Error Testing:**
```python
with pytest.raises(ValidationError, match="extra"):
    Document(..., unexpected_field="disallowed")      # tests/test_models.py:67

with pytest.raises(PermissionError, match="Cloud transmission blocked"):
    unconsented_cloud.generate_text("Test prompt")     # tests/test_cloud_privacy.py:34

with pytest.raises(RuntimeError, match="llama-server generation failed"):
    provider.generate_text("test")                    # tests/test_llama_cpp_provider.py:128
```
Always include a `match=` fragment for message-bearing errors; use `pytest.raises(ValidationError)` without `match` only when any validation failure is acceptable.

**CLI Output Testing:**
```python
# tests/test_start_launcher.py:11-16
def test_banner_prints(capsys):
    """Verify startup banner prints system name and features."""
    start.print_banner()
    captured = capsys.readouterr()
    assert "Local-First Multimodal PDF Intelligence System" in captured.out
```
Use `capsys` for `print()`-based CLI code (`start.py`, `setup.py`); use a custom `logging.Handler` when asserting log records (`tests/test_logging_setup.py:57-67`).

**Session-State Testing:**
Seed every key the code reads before calling it; missing keys raise `AttributeError` on `st.session_state`. Follow `tests/test_ui_smoke.py:19-35` as the canonical seed list, and extend it when `main.py` adds new session keys.

**Known Mock-Fidelity Pitfall:**
Several mock providers call `HealthStatus(status="healthy", message=..., provider_type="local")`, but `HealthStatus` in `model_provider.py:44-61` declares only `status`, `message`, and `latency_ms` with `extra="forbid"`. Because those tests never invoke `check_health()`, the invalid construction is never executed:
- `tests/test_concurrency_lock.py:20`
- `tests/test_main_ui.py:229`
- `tests/test_summarizer.py:24`
- `scripts/benchmark_multimodal.py:40`
- `scripts/profile_resources.py:49`

When writing a new mock provider, construct `HealthStatus` with only schema fields. If you add a test that calls `check_health()` on one of these mocks, it will raise `pydantic.ValidationError`.

## Checklist for New Tests

1. Place the file at `tests/test_<module>.py`; start with a docstring naming the module and the invariants covered.
2. Name tests `test_<behavior>_<condition>`; add `-> None` on new tests.
3. One behavior per test, with a one-line docstring.
4. Use `tmp_path` for any file/database/index; never write into `data/` or `.cache/`.
5. Mock at the narrowest seam: `httpx.MockTransport` for HTTP, `monkeypatch.setattr` for module-level optional deps, a `BaseModelProvider` subclass for provider behavior.
6. Reset global state with an autouse fixture if the code touches `st.session_state`, `InferenceGate`, or telemetry caches.
7. Assert both the positive outcome and, where relevant, the negative/fallback path and request payload.
8. Verify offline safety: no real network, no model downloads, no GPU allocation.
