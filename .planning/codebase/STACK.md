## Configuration

**Environment:**
- Local dev: `.env` in repo root holding `GROQ_API_KEY` (and optionally `OPENAI_API_KEY` / `ANTHROPIC_API_KEY`); loaded by `load_dotenv()` before `AiModel`/provider construction; `.env` is gitignored (`.gitignore:1`) and ABSENT from working tree (verified — `ls .env*` returns nothing)
- Cloud deploy: Streamlit secrets (`st.secrets["GROQ_API_KEY"]` tried first, `except (KeyError, FileNotFoundError)` → `os.environ`); no `.streamlit/secrets.toml` committed (verified — no `.streamlit/` directory)
- Key precedence contract (must-follow): explicit arg → Streamlit session state → `st.secrets` → env var → raise `ValueError` naming both locations (`litellm_provider.py:42+`, `groq_provider.py`, `local_llm.py`)
- Runtime model routing: `DEFAULT_CLOUD_MODEL = "groq/llama-3.3-70b-versatile"` (`litellm_provider.py`); `KNOWN_CONTEXT_WINDOWS` per prefix (groq 131072 / openai 128000 / anthropic 200000); vision-gated prefixes `openai/gpt-4o*`, `anthropic/claude-3*`
- Local inference: `LlamaCppProvider(base_url="http://127.0.0.1:8080", model_name="qwen3-vl-2b", context_window=4096)`; non-loopback URLs rejected unless `allow_remote=True`; GGUF path + `mmproj` documented in `docs/LOCAL_INFERENCE.md`
- Data dirs: `data/` gitignored (`.gitignore`); LanceDB at `data/lancedb` (`hybrid_retriever.py:27`); DocStore SQLite + cache helpers `cache_dir_for` (`models.py`); purge paths `DocStore.purge_all` + `HybridRetriever.purge` added in audit commit `619814a` (P1-1)

## Platform Requirements

**Development:**
- Python 3.11+, pip (or `uv`), virtualenv (`.venv`, gitignored); Windows users may need Developer Mode / admin terminal for HuggingFace symlink model download (`README.md`)
- A Groq API key only for cloud-fallback paths (free at `console.groq.com`); public `all-MiniLM-L6-v2` needs no HF token
- `nvidia-smi` optional — telemetry degrades gracefully on CI/headless (`resource_telemetry.py`); live RTX 3050 profile recorded in `.planning/research/RESOURCE_PROFILE.json` (projected peak 3450 MB vs 4096 MB hardware, 646 MB headroom, P0-2)
- Run: `pip install -r requirements.txt && streamlit run main.py` (README); reproducible: `uv pip install --system -r requirements-lock.txt -r requirements-test.txt`

**Production:**
- Streamlit Community Cloud hosting the `main.py` app with `GROQ_API_KEY` in the Cloud secrets panel; HF model re-downloaded on first boot; in-memory + `data/`-local persistence only — no managed DB/volume required
- Local workstation target: single-user, 4 GB VRAM ceiling; only one LLM/VLM resident at a time; quantized GGUF; 4K–8K context; preprocessing (Docling/RapidOCR/embeddings) CPU-sequenced
