## Platform Requirements

**Development:**
- Python 3.11+, pip, virtualenv (`.venv`, gitignored `.gitignore:2`).
- Windows host targeted (PowerShell/batch); Docker path provided for Linux. `setup.py` and `start.py` reconfigure stdout/stderr to UTF-8 for Windows consoles (`setup.py:31-41`, `start.py:21-31`).
- `llama-server` binary auto-downloaded to `tools/llama-server/` per platform/arch: Windows CUDA 12.4 or CPU, Linux CUDA 12.8 or CPU (`setup.py:288-493`). Pin: release `b11718` from `github.com/ggml-org/llama.cpp` with `ggerganov` mirror (`setup.py:288-290`).
- Model acquisition: GGUF weights + mmproj from HuggingFace mirrors into `models/` (`setup.py:59-78`); embedding + OCR weights pre-cached (`setup.py:196-233`).

**Production:**
- Local single-user workstation: Streamlit + llama-server on the same machine over loopback (`README.md:214`).
- Docker: `docker compose up` (app) or `docker compose --profile gpu up` (bundled CUDA llama-server, `docker-compose.yml:29-51`); ports `8501` (app) and `8080` (llama-server); bind mounts `./data`, `./models`, `./.cache` (`docker-compose.yml:9-13`).
- Hosted Streamlit cannot reach laptop-loopback llama-server — requires dedicated endpoints or private tunneling (`README.md:216`).
- Strict 4 GB VRAM envelope: one LLM/VLM active at a time enforced by `InferenceGate` (`local_llm.py:26-90`); embeddings pinned to CPU (`local_embedding.py:55,64-65,70`).
