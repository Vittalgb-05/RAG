## Platform Requirements

**Development:**
- Windows 11 + PowerShell preferred (primary developer host); Linux/macOS supported via Docker or compatible toolchain.
- Python 3.11+, `pip`, virtualenv (`.venv`).
- NVIDIA GPU optional but assumed for local VLM: CUDA 12.x driver (550.x+), ~4 GB VRAM target (`docs/RUNBOOK.md:7-17`, `docs/LOCAL_INFERENCE.md:11-22`).
- 16 GB system RAM, ~10 GB free SSD for models + binary + caches.
- Native `llama-server` binary either on `PATH` or in `tools/llama-server/` (`start.py:69-79`, `setup.py:302-305`).
- HuggingFace model cache in `~/.cache/huggingface/` for `all-MiniLM-L6-v2`.

**Production:**
- Single Docker container serving Streamlit on `8501`; SQLite/LanceDB/model volumes mounted from host.
- Or native launch via `python start.py`, which probes/spawns `llama-server` on `8080` and then runs Streamlit.
- Hosted deployment cannot reach a laptop loopback `llama-server`; requires a reachable model endpoint or private tunnel (`README.md:216`).
- No external managed services are required in the default local-only mode.

## Stack Notes & Drift Risks

- `requirements.txt` uses floors for Docling, LanceDB, PyMuPDF, RapidOCR, LiteLLM, Pillow, and pyarrow; `requirements-lock.txt` supplies exact versions. Docker builds from `requirements.txt`, while CI uses the lockfile — installations can therefore differ (`Dockerfile:25-27`).
- `setup.py` is a dual-purpose file: packaging metadata plus an opinionated installer that performs network downloads (HuggingFace, GitHub releases, pip). Calling setuptools commands requires no extra arguments; the custom CLI branch intercepts setup-style invocations (`setup.py:780-820`).
- `tools/llama-server/` (~1.1 GB of CUDA DLLs) and `models/` (~2.3 GB GGUF) are present locally but excluded from git; fresh clones must run `python setup.py` before local inference.
- `rag_assistant.egg-info/` reflects the last editable install and should be regenerated rather than edited.
- `ui/` is a first-party package (no external UI kit); icons and brand assets are local SVGs under `assets/`, keeping the browser free of CDN dependencies (`tests/test_ui_smoke.py:34-40`).
