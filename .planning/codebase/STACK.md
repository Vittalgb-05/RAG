# Technology Stack

**Analysis Date:** 2026-10-21

## Languages

**Primary:**
- Python 3.11+ — all application code. Root modules (`main.py`, `start.py`, `setup.py`, `doc_store.py`, `hybrid_retriever.py`, `local_llm.py`, `summarizer.py`, etc.), the `ui/` package, `scripts/`, and `tests/`.
  - Declared minimum: `python_requires=">=3.11"` in `setup.py`.
  - Pinned runtime: `python:3.11-slim-bookworm` in `Dockerfile`; `python-version: "3.11"` in `.github/workflows/ci.yml`; `mcr.microsoft.com/devcontainers/python:1-3.11-bookworm` in `.devcontainer/devcontainer.json`.
  - Conditional support for Python >= 3.13 in `requirements.txt` (RapidOCR package swap).

**Secondary:**
- TOML — `.streamlit/config.toml`, `pyproject.toml`
- YAML — `.github/workflows/ci.yml`, `docker-compose.yml`
- Markdown — LLM prompts and grounded document context are rendered as Markdown (see `prompt_budget.py`, `summarizer.py`)
- JSON — disk cache artifacts (`.cache/<sha256>/<version>/{manifest,pages,chunks}.json`) and fallback vector store (`data/lancedb/fallback_store.json`)

**Not present:** JavaScript, TypeScript, CSS, or HTML source files. The UI is server-rendered Streamlit Python; styling is injected CSS strings from `ui/theme.py`, and icons are static SVGs in `assets/icons/` generated by `scripts/generate_icons.py`.

## Runtime

**Environment:**
- CPython 3.11 on Windows 11 (primary target) and Linux x86_64 (Docker / CI).
- Streamlit web server on port `8501` (`.streamlit/config.toml`, `start.py`, `Dockerfile`).
- Native `llama-server` (llama.cpp release `b11718`) bound to `127.0.0.1:8080`; launched by `start.py --start-llama` or the optional `llama-server` Compose service.
- Single-user, single-process design; inference serialized by `InferenceGate` in `local_llm.py` (class-level `threading.RLock`).

**Package Manager:**
- `pip` (`setup.py` invokes `python -m pip install -r ...`; `Dockerfile` uses `pip install`).
- Lockfile: present — `requirements-lock.txt`, generated by `uv pip compile --universal --python-version 3.11 requirements.txt`.
- CI installs with `uv pip install --system -r requirements-lock.txt` (`.github/workflows/ci.yml`).
- Packaging: setuptools via `setup.py` (`name="rag-assistant"`, `version="1.0.0"`, `find_packages()`).

## Key Dependencies

**Critical:**
- `streamlit==1.42.0` — the only UI runtime; `main.py` is the Streamlit script entry point.
- `lancedb==0.40.0` / `pyarrow==23.0.1` — hybrid retrieval (dense cosine + FTS); gracefully degrades to `vector_index.VectorIndex` when unavailable (`hybrid_retriever.py`, `vector_index.py`).
- `sentence-transformers==3.4.1` — `all-MiniLM-L6-v2`, 384-dim, L2-normalized, CPU-pinned with process-level model cache (`local_embedding.py`).
- `pymupdf==1.28.2` — PyMuPDF is AGPL-3.0/commercial dual-licensed; flagged in `docs/LICENSES.md`.
- `docling==2.138.0` — primary extraction path; `pdf_reader.py` (pypdf 5.3.0) is the automatic fallback.
- `pydantic==2.11.9` — validates all persisted/transferred payloads.

**Infrastructure:**
- `psutil==6.1.1` — RSS/VMS telemetry (`resource_telemetry.py`).
- `nvidia-smi` (external binary, not a package) — GPU VRAM utilization with 5s TTL cache (`resource_telemetry.py`).
- `python-dotenv==1.0.1` — loads `.env` at `main.py:151` via `load_dotenv()`.
- `langchain-text-splitters==0.3.6` — `RecursiveCharacterTextSplitter(chunk_size=1000, chunk_overlap=200)` in `docling_reader.py`, `pdf_reader.py`, `ocr_fallback.py`.
- `numpy>=1.26.0,<3.0.0` — locked at 2.4.6.

## Configuration

**Environment:**
- Configuration precedence for cloud keys: explicit argument → `st.session_state.cloud_api_keys` → `st.secrets` → `os.environ` (`litellm_provider.py:44`).
- `.env` file is gitignored (`.gitignore`) and loaded by `python-dotenv`; no `.env` file is committed or present in the working tree.
- Documented environment variables:
  - `LLAMA_SERVER_URL`, `LLAMA_SERVER_HOST`, `LLAMA_SERVER_PORT` (default `8080`) — `llama_cpp_provider.py:45`.
  - `GROQ_API_KEY`, `OPENAI_API_KEY`, `ANTHROPIC_API_KEY` — cloud adapters; passed through by `docker-compose.yml`.
  - `LITELLM_TELEMETRY=False` — forced default in `litellm_provider.py:19`.
  - `USE_TF=0`, `USE_TORCH=1`, `TF_ENABLE_ONEDNN_OPTS=0` — set in `main.py`, `start.py`, `local_embedding.py`, `setup.py`, `Dockerfile`, `docker-compose.yml`.

**Build:**
- `pyproject.toml` — Ruff lint/format and pytest `testpaths=["tests"]`, `python_files=["test_*.py"]`, `python_functions=["test_*"]`, ignores `UserWarning`/`DeprecationWarning`.
- `setup.py` — dependency parsing from `requirements.txt`, packaging metadata, model registry (Hugging Face GGUF URLs), llama-server binary acquisition for Windows/Linux (`b11718`).
- `requirements.txt` — 18 direct runtime pins/floors; `requirements-lock.txt` — 645-line universal lock; `requirements-test.txt` — pytest, reportlab, ruff, psutil.
- `.streamlit/config.toml` — AMOLED dark theme (`base="dark"`, `backgroundColor="#050608"`, `primaryColor="#B9A3FF"`), `maxUploadSize = 50` MB, CORS + XSRF enabled, `gatherUsageStats = false`.
- `.dockerignore` — excludes `data/`, `models/`, `tools/`, `.cache/`, `tests/`, `.env`, `.planning/`.

## Platform Requirements

**Development:**
- Python 3.11+ and pip/uv.
- Windows PowerShell (primary) or Linux bash.
- Optional NVIDIA GPU with driver (`nvidia-smi`) for CUDA llama-server; CPU builds supported.
- `libgl1`, `libglib2.0-0`, `libgomp1`, `build-essential`, `curl` on Debian (see `Dockerfile`).
- Local model artifacts (gitignored, `models/`): `qwen3-vl-2b-instruct-q4_k_m.gguf`, `mmproj-f16.gguf`.
- Local llama-server binary in `tools/llama-server/` (gitignored) or on `PATH`.

**Production:**
- Single-user workstation deployment; `docker-compose.yml` exposes `127.0.0.1:8501` only.
- Optional `gpu` Compose profile runs `ghcr.io/ggml-org/llama.cpp:server-cuda` with `-c 4096 -ngl 28`.
- Healthcheck: `curl -f http://localhost:8501/_stcore/health`.
- Startup commands: `python start.py --start-llama`, `streamlit run main.py`, `docker-compose up`.
