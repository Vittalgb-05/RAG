## Optional-Dependency Pattern (must-follow)

Every heavy/optional third-party import uses the `try/except ImportError → None` guard at module top, a boolean/`is None` availability check at use site, and graceful degradation — never a hard import. Copy this shape exactly:

```python
try:
    import lancedb
    import pyarrow as pa
except ImportError:
    lancedb = None  # type: ignore[assignment]
    pa = None  # type: ignore[assignment]
```

Instances to mirror:
- `lancedb` + `pyarrow` guard → `_has_lancedb` flag, disk-backed JSON fallback store, `is_persistent()` predicate (`hybrid_retriever.py:18-24, 100-124, 202-204`). LanceDB init failure degrades to fallback with `logger.warning`, never a raise (`hybrid_retriever.py:118-121`).
- `groq` guard → `Groq = None`, health returns `unreachable` with install hint, `generate/stream` raise `RuntimeError` (`groq_provider.py:12-15, 59-83, 106-108`).
- `docling` guard → five `None` names (`docling_reader.py:22-31`); `self._has_docling` flag + `PdfReader` fallback for the whole document (`docling_reader.py:70-72, 95-100`) and empty-extraction fallback (`docling_reader.py:183-191`) and exception fallback (`docling_reader.py:288-293`).
- `rapidocr_onnxruntime` + `fitz` guards (`ocr_fallback.py:18-26`); `is_available()` requires both renderer and recognizer (`ocr_fallback.py:71-75`); missing renderer yields `None` image → page kept as-is (`ocr_fallback.py:217-232`); missing recognizer yields `("", 0.0)` (`ocr_fallback.py:131-132`).
- `fitz` guard in visual path (`visual_analyzer.py:17-20`); `detect_visual_regions` returns `[]` with `logger.warning` when absent (`visual_analyzer.py:59-61`); `crop_visual_element` raises `RuntimeError` only when a crop is actually requested without `fitz` (`visual_analyzer.py:164-165`).
- `local_llm.py` keeps the same `Groq`-era shape via provider health probing (local-first, Groq fallback, diagnostic default).
- `psutil` is a soft dependency inside `get_process_memory_info()`: function-level `import psutil` with `except ImportError → {"rss_mb": 0.0, "vms_mb": 0.0}` (`resource_telemetry.py:82-93`). `nvidia-smi` is an external binary, not a package: `FileNotFoundError` / `SubprocessError` / `TimeoutExpired` (2.0 s timeout) → `None` with `logger.debug` (`resource_telemetry.py:39-71`).

New optional dependencies MUST follow this pattern: guarded import, `is_available()`/`check_health()`/`is_persistent()` predicate, fallback path that preserves existing data, `logger.warning` (never `print`) — or `logger.debug` for expected-absent telemetry probes (`resource_telemetry.py:67,70,92,95`).

## Concurrency Idioms (must-follow, Phase 6 QUAL-01)

- `InferenceGate` (`local_llm.py:26-90`) is a process-level reentrant lock guaranteeing max ONE active GPU inference operation inside the 4 GB VRAM envelope. Shape: class-level `threading.RLock()` (`_lock`) + `threading.Lock()` (`_state_lock`) + `_active_threads: int` counter (`local_llm.py:34-36`). `acquire(timeout=60.0)` / `release()` / `is_locked()` (counter read under `_state_lock`, never the raw lock state) / `hold(timeout)` context manager raising `TimeoutError("InferenceGate acquisition timed out ...")` on expiry.
- Release-before-decrement order is load-bearing (CR-01 fix): `cls._lock.release()` runs FIRST so an unowned release raises `RuntimeError` immediately without corrupting `_active_threads`; the counter decrement runs only after a successful release (`local_llm.py:54-63`). Never reorder these lines. The regression test is `tests/test_concurrency_lock.py::test_unauthorized_release_does_not_corrupt_active_counter`.
- Guard every LLM entry point: `AiModel.ask_a_question_from_pdf_stream` acquires with `timeout=60.0`, yields a single `"System is busy processing another inference request"` warning token when acquisition fails, and releases in `finally` (`local_llm.py:258-271`); `AiModel.generate_text` wraps the provider call in `with InferenceGate.hold(timeout=timeout)` (`local_llm.py:281-293`); `Summarizer.summarize_document` executes the single-pass/map-reduce branch inside `with InferenceGate.hold(timeout=120.0)` (`summarizer.py:387-388`).
- Reentrancy is intentional: `threading.RLock` lets the same thread nest `hold()` blocks (e.g. summarizer calling `generate_text` under an outer hold) without deadlocking — covered by `test_inference_gate_reentrancy_in_same_thread`.
- Tests MUST drain the gate with the autouse `ensure_gate_released` fixture (`while InferenceGate.is_locked(): InferenceGate.release()` before AND after each test, `tests/test_concurrency_lock.py:61-68`) so a leaked hold never poisons the suite.

## Telemetry Idioms (must-follow, Phase 6 QUAL-01)

- All resource telemetry goes through `resource_telemetry.py`. Probes never raise: `get_gpu_memory_info()` returns `dict(total_mb, used_mb, free_mb, utilization_pct)` or `None` (`resource_telemetry.py:26-71`); `get_process_memory_info()` returns `dict(rss_mb, vms_mb)` with zero-dict fallback (`resource_telemetry.py:74-96`).

## Prompt-Budget / Injection-Defense Idioms (must-follow)

- All grounding goes through `assemble_grounded_messages(prompt, context_text="", history=None, max_context_tokens=4096, max_output_tokens=1024)` (`prompt_budget.py:48-128`). Never hand-assemble system prompts elsewhere.
- Token math: `estimate_tokens(text) = max(1, ceil(len/4))`, `0` for empty/falsy (`prompt_budget.py:34-45`). Budget order is fixed: `total_input_budget = max(256, max_context_tokens - max_output_tokens)` → bound user prompt first (truncate + `"\n[... prompt truncated ...]"`) → bound context (truncate + `"\n[... truncated ...]"`) → fill history newest-first with `+4` tokens overhead per turn, oldest dropped first, then prune leading assistant turns (`prompt_budget.py:67-122`, WR-02 fix at `prompt_budget.py:120-122`).
- Session-memory bounding goes through `bound_chat_history(history, max_turns=50)` (`prompt_budget.py:131-152`): slice to the last `max_turns` turns, then pop leading `"assistant"` turns so the retained history starts with a `"user"` turn (WR-02 fix). `main.py:389-395` funnels every append through `append_chat_turn` → `bound_chat_history(..., max_turns=MAX_CHAT_TURNS)`. The sanitizer is case-insensitive and whitespace-tolerant: `re.sub(r"</?\s*document_context\s*>", ..., flags=re.IGNORECASE)` (WR-09 fix, `prompt_budget.py:30`).
- LanceDB filter strings are SQL-like — escape single quotes before interpolation: `doc_id.replace("'", "''")`, `cid.replace("'", "''")` (CR-03 fix, `hybrid_retriever.py:219,328,357`). Never interpolate raw user/document-controlled IDs into `.where()` / `.delete()` filters.

- All grounded-QA verification goes through `validate_citations(response_text, retrieval_result=None) -> CitationVerificationResult` (`citation_validator.py:81-181`). ## Ingestion Idioms (must-follow)

- Chunking is always `RecursiveCharacterTextSplitter(chunk_size=1000, chunk_overlap=200, length_function=len)` (`pdf_reader.py`, `docling_reader.py:172-176`, `ocr_fallback.py:188-192`). Markdown tables starting with `|` and ≤2000 chars stay intact as one chunk; prose is split (`docling_reader.py:226-267`).
- Chunk IDs are `{sha12}_p{page}_{index:04d}` with a per-page monotonic counter that increments only on emitted chunks (`docling_reader.py:227,254`, `ocr_fallback.py:280`); `char_start`/`char_end` come from progressive `str.find(content, current_offset)` (`docling_reader.py:219-252`, `ocr_fallback.py:274-278`).
- Identity: `sha256_bytes` (1 MiB slices) → `doc_id_for` (`doc_<sha16>`, strict `^[0-9a-f]{64}$` validation) (`upload_validation.py:19-48`); chunk `doc_id` and `filename` threaded through every layer; `extraction` provenance is one of `pypdf` / `docling` / `ocr` (`models.py:71`); VLM descriptions carry `source="vlm:<model_name>"` and NEVER overwrite table ground truth (`visual_analyzer.py:240,251-261`).
- Page fault isolation: per-page `try/except` → `status="failed"` with `error=str(err)` and `num_chunks=0`, sibling pages unaffected (`ocr_fallback.py:306-318`; same shape in `pdf_reader.py` / `docling_reader.py`). OCR empty-result preserves pre-existing partial chunks (WR-04 fix, `ocr_fallback.py:237-262`). Conditional OCR gate: `should_ocr_page(text, status, threshold=50)` — `empty`/`failed` always OCR, else only if `len(strip) < threshold` (`ocr_fallback.py:29-43`); clean pages bypass OCR entirely, retaining original chunks (`ocr_fallback.py:210-214`).
- Phase 6 dual-index rule (06-02): `HybridRetriever` is the SOLE authoritative retrieval index in `st.session_state` — do NOT call `st.session_state.local_embedding.build_index(...)` during upload or restart restoration. `LocalEmbedding` is retained strictly as the CPU embedding vectorizer for query/batch encoding. `contains_document` is the preferred existence alias (`hybrid_retriever.py:226`, used in `tests/test_cache_invalidation.py:199-205`).
- Visual detection thresholds: raster images ≥30×30 pt; vector-diagram cluster ≥2 drawings, union rect ≥40×40 pt, full-page borders (>95% area) excluded, +10 pt padding (`visual_analyzer.py:73-130`). Crops render at `zoom=2.0` (clamped `≥0.5`), clipped to page rect, empty intersections raise `ValueError` (`visual_analyzer.py:138-183`).
- Upload validation order is fixed: `%PDF-` magic bytes → size (`MAX_FILE_MB=50`) → `pypdf` page probe → count (`1..MAX_PAGES=500`) → hash → `ValidatedUpload` frozen dataclass (`upload_validation.py:64-113`). All failures raise `ValueError` with user-actionable `— {filename}` suffix.

BM25 fallback precomputes `df_map` once outside the scoring loop — O(N·|Q|), never per-document rescans (WR-03 fix, `hybrid_retriever.py:449-452`). `_save_fallback_store` normalizes `BBox` via `model_dump()` before `json.dump` (WR-04 fix, `hybrid_retriever.py:168-176`).

## Persistence Idioms (must-follow)

- `DocStore(db_path)` (`doc_store.py:78-96`): `Path.resolve()`, `mkdir(parents=True, exist_ok=True)`, apply `MIGRATIONS` by `PRAGMA user_version` on init.

## Error Handling

**Patterns:**
- Fail fast with `TypeError` (wrong type) / `ValueError` (bad value) before mutating state: metric whitelist, `content`-key checks, dimension lock-in (`vector_index.py`); `doc_id`/`sha` hex validation (`models.py:28-30`, `upload_validation.py:46-48`); empty `image_bytes` → `ValueError` (`llama_cpp_provider.py:236-237`); bad bbox → `ValueError` (`visual_analyzer.py:156-172`); `index_chunks` non-Chunk/non-dict → `TypeError`, chunk/embedding length mismatch → `ValueError`, missing embedder → `ValueError` (`hybrid_retriever.py:252-264`); empty chunks → `return 0` (`hybrid_retriever.py:241-242`); unknown summary profile → `ValueError` naming allowed profiles (`summarizer.py:322-325`); no extractable page text → `ValueError` before inference/caching (`summarizer.py:381-382`).
- `check_health()` / `is_persistent()` / `get_gpu_memory_info()`-None-leg / `get_process_memory_info()`-zero-leg never raise (return `HealthStatus` / `bool` / `None` / zero-dict); generation/streaming raise `RuntimeError` with operation-prefixed messages (`llama-server generation failed`, `Groq API error`, `image analysis failed`) chained via `from exc`. LanceDB search failures degrade with `logger.warning`/`logger.debug` to the next fallback leg, never a raise (`hybrid_retriever.py:389-390, 503, 540`).
- Gate contention is a typed busy-signal, not an exception: `InferenceGate.acquire` returns `False` on timeout; `hold()` raises `TimeoutError("InferenceGate acquisition timed out ...")` for direct users (`local_llm.py:82-86`); the streaming chat path converts contention into a single yielded busy-warning token (`local_llm.py:258-271`). Summarizer gate timeout is `120.0` s (long map-reduce), chat/stream timeout is `60.0` s.
- Empty-query guards return typed empties, not errors: `search_hybrid("", k)` / `k <= 0` → empty `RetrievalResult(search_mode="hybrid")` (`hybrid_retriever.py:523-529`); `search_dense`/`search_fts` with `k <= 0` (or blank query) → `[]` (`hybrid_retriever.py:375-376, 488-489`); `bound_chat_history([], ...)` → `[]` (`prompt_budget.py:144-145`).
- Per-file/per-page `try/except` with isolate-and-continue: one corrupt PDF never aborts the batch (`main.py` upload loop); one bad OCR page never aborts the document (`ocr_fallback.py:306-318`); one failed VLM call yields `[Visual element: analysis failed: ...]` placeholder (`visual_analyzer.py:236-239`).
- Missing `GROQ_API_KEY` surfaces via `HealthStatus(status="unreachable")` with remediation text, not an exception at import (`groq_provider.py:70-74`).

## Function Design

**Size:** Small single-purpose methods (5–40 lines). Longest are `DoclingReader.extract_text` (~210 lines, sequential pipeline stages), `apply_conditional_ocr` (~150 lines, per-page loop), `Summarizer.summarize_document` (~118 lines, staged cache → reconstruct → route → verify → persist pipeline), `HybridRetriever.index_chunks`/`search_hybrid`/`_bm25_search_fallback` (~110/115/60 lines, staged pipelines), and `run_resource_profile` (`scripts/profile_resources.py:94-338`, six sequential benchmark stages) — these are staged pipelines, not logic to extract, unless adding genuinely new stages.

Phase-5 defaults: `profile="overview"`, `force_refresh=False`, `max_tokens=1500/800/1000` per summarizer stage, `max_page=None`, `retrieval_result=None`. Phase-6 defaults: `timeout=60.0` (gate acquire) / `timeout=120.0` (summarizer hold) / `timeout=2.0` (`nvidia-smi` probe, gate test holds), `max_turns=50` (`bound_chat_history`, `prompt_budget.py:133`), `record_history=True` (`LatencyTracker`, `resource_telemetry.py:102`). Injectable collaborators default to `None` and are constructed lazily: `converter`, `recognizer`, `renderer`, `region_detector`, `cropper`, `transport`, `engine`, `provider`, `embedding_fn`, `doc_store` (`docling_reader.py:41`, `ocr_fallback.py:51-53,166`, `visual_analyzer.py:35-38,189`, `llama_cpp_provider.py:26`, `local_llm.py`, `hybrid_retriever.py:83-87`, `summarizer.py:155`).

**Return Values:** Data methods return plain containers or Pydantic models: `list[dict]` chunks with `content`/`filename`/`page`/`chunk_id`/`doc_id` keys; `list[Page]` records; `list[EvidenceElement]`; `tuple[list[Page], list[dict]]` from `apply_conditional_ocr`; `RetrievalResult` (frozen, `search_mode`-tagged) from `search_hybrid`; `list[dict]` with `score` key from `search_dense`/`search_fts`; `SummaryResult` (frozen metadata + `page_references: list[int]`) from `summarize_document`; `CitationVerificationResult` (frozen, `is_valid`/`precision`/`valid_citations`/`hallucinated_citations`/`cited_ranks`/`abstention_detected`/`message`) from `validate_citations`; `HealthStatus` (never raises) vs `str` generation (raises `RuntimeError`). Telemetry returns nullable/zero-safe shapes: `dict | None` from `get_gpu_memory_info`, zero-dict from `get_process_memory_info`, snapshot dict from `get_system_telemetry_snapshot`/`LatencyTracker.to_dict()`; counters return `int` from `count_documents`/`count_summaries`; `bound_chat_history` returns a NEW list (never mutates the input); `InferenceGate.acquire` returns `bool`. Generation entry points MUST be generators yielding `str` fragments (`stream_text`), consumed by `st.write_stream`.

## Module Design

**Exports:** Single public class (or function trio for `prompt_budget`/`upload_validation`/`citation_validator`, or class + `compute_rrf`/`DEFAULT_DB_URI`/`DEFAULT_RRF_K` for `hybrid_retriever`, or class + `extract_page_references`/`PROFILE_SYSTEM_INSTRUCTIONS`/`MAP_PROMPT_TEMPLATE`/`REDUCE_PROMPT_TEMPLATE` for `summarizer`, or class `InferenceGate` + class `AiModel` for `local_llm`, or `LatencyTracker` + `track_stage` + six module functions + `MAX_STAGE_HISTORY` for `resource_telemetry`) per module, imported by name — no `__all__`, no factories, no re-exports.

**Barrel Files:** None and not wanted: the flat layout means a new module is just a new root-level file plus an import where used.

## Config Patterns (must-follow)
