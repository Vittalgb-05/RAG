# Coding Conventions

**Analysis Date:** 2026-10-10

## Naming Patterns

**Files:**
- Flat `snake_case.py` modules at repo root, one class per file (except `main.py`, which is the Streamlit entry point): `main.py`, `local_llm.py`, `local_embedding.py`, `vector_index.py`, `pdf_reader.py`.
- Test files live under `tests/` as `test_<module>.py`: `tests/test_vector_index.py`, `tests/test_pdf_reader.py`, `tests/test_local_embedding.py`, `tests/test_local_llm.py`. Shared fixtures in `tests/conftest.py`; package marker `tests/__init__.py` (single docstring).
- Utility scripts live under `scripts/`: `scripts/benchmark_baseline.py`. Synthetic corpus generator at `tests/data/corpus/generate_corpus.py`; generated corpus PDFs (`clean_digital.pdf`, `multi_column.pdf`, `dense_table.pdf`, `scanned_sample.pdf`, `chart_diagram.pdf`, `corrupt_invalid.pdf`) are build artifacts regenerated by CI, not hand-written fixtures.
- No packages, no barrel files. Imports are direct module imports (e.g. `from local_llm import AiModel` in `main.py:21`).

**Classes:**
- `PascalCase`, one public class per module: `AiModel` (`local_llm.py:11`), `LocalEmbedding` (`local_embedding.py:11`), `VectorIndex` (`vector_index.py:15`), `PdfReader` (`pdf_reader.py:7`).
- Test-only doubles use `Mock`-prefixed class names defined inside fixtures, never at module scope: `MockDelta` / `MockChoice` / `MockChunk` inside `mock_groq_client` (`tests/conftest.py:27-37`).

**Functions / methods:**
- `snake_case` throughout. Examples: `ask_a_question_from_pdf_stream` (`local_llm.py:36`), `build_index` / `get_embeddings` / `get_context` (`local_embedding.py:35,42,67`), `add_document` / `add_vector` / `search` (`vector_index.py:40,66,97`), `extract_text` / `get_paragraphs` (`pdf_reader.py:26,71`), `load_ai_model` / `save_uploaded_pdf` (`main.py:60,70`).
- Test functions are `test_<unit>_<behavior>`: `test_cosine_distance_math`, `test_add_vector_guards`, `test_search_ranking` (`tests/test_vector_index.py`), `test_pdf_reader_extract_text_digital`, `test_pdf_reader_bytesio_stream` (`tests/test_pdf_reader.py`), `test_local_embedding_build_index`, `test_local_embedding_get_context` (`tests/test_local_embedding.py`), `test_ai_model_missing_key_raises`, `test_ai_model_streaming_yield` (`tests/test_local_llm.py`).
- Corpus generator functions are `generate_<variant>_pdf`: `generate_clean_digital_pdf`, `generate_multi_column_pdf`, `generate_dense_table_pdf`, `generate_scanned_sample_pdf`, `generate_chart_diagram_pdf`, `generate_corrupt_invalid_pdf`, plus `generate_all_corpus_files` and `get_corpus_dir` (`tests/data/corpus/generate_corpus.py:22-207`).
- Benchmark helpers are `get_current_rss_mb` / `run_benchmark` (`scripts/benchmark_baseline.py:23-28`).
- Private helpers use a single leading underscore: `_embed_one` (`local_embedding.py:28`), `_cosine_distance` / `_euclidean_distance` / `_dot_product` / `_magnitude` (`vector_index.py:150,165,201,206`).
- Private state uses a single leading underscore: `_vector_dim`, `_distance_metric`, `_embedding_fn` (`vector_index.py:32-34`).

**Variables / attributes:**
- `snake_case` locals and attributes: `indexed_files`, `document_metadata`, `local_embedding`, `chat_history` (`main.py:46-49`), `page_chunks`, `pages_text`, `filename` (`pdf_reader.py:16-23`), `groq_client`, `model_name` (`local_llm.py:18,33`).
- Constants are inline literals, not module-level `UPPER_CASE` names — e.g. `chunk_size=1000, chunk_overlap=200` (`pdf_reader.py:32-33`), `k=10` call sites (`main.py:216,233`, `local_llm.py:54`), `max_tokens=1024` (`local_llm.py:77`).

**Types:**
- `typing` generics used only in `vector_index.py` (`List`, `Dict`, `Tuple`, `Optional`, `Any` — `vector_index.py:12` plus annotations on every public method). `local_embedding.py` uses builtin generics sparingly (`list[float]`, `list[str]`, `list[tuple[dict, float]]`). `main.py`, `local_llm.py`, `pdf_reader.py` are mostly untyped except isolated hints (`-> str`, `-> AiModel`, `pdf_path: str, prompt: str`).
- Benchmark report dicts are untyped plain `dict` with string keys (`scripts/benchmark_baseline.py:129-159`).

## Code Style

**Formatting:**
- Ruff is the formatter/linter of record (config in `pyproject.toml:1-11`). `line-length = 120`, `target-version = "py311"`. No `pyproject.toml`-era hand style remains; CI enforces `ruff check .` (`.github/workflows/ci.yml:30-32`).
- 4-space indentation. `E501` (line length) is ignored in ruff config, so long f-strings/prompts are tolerated (e.g. `local_llm.py:56-62`).
- Mixed quote style: double quotes for code/strings, single-quoted `'''...'''` docstrings in `main.py:61-77` and `local_llm.py:13,37`, double-quoted `"""..."""` docstrings in `local_embedding.py` and `vector_index.py`. When adding code, match the surrounding file rather than normalising repo-wide.

**Linting (must-follow):**
- Run `ruff check .` before pushing — CI fails the build on any violation (`.github/workflows/ci.yml:30-32`). Verified clean with `ruff 0.15.12`.
- Enabled rules: `select = ["E", "F", "W"]` (`pyproject.toml:6`); ignored: `E501` (long lines OK), `W291`/`W293` (trailing whitespace tolerated) (`pyproject.toml:7`).
- Per-file ignores: `scripts/*` ignores `E402` (module-level import not at top — needed for the `sys.path.insert` bootstrap in `scripts/benchmark_baseline.py:16-20`); `tests/*` ignores `F401`/`F841` (unused imports/variables tolerated in tests) (`pyproject.toml:9-11`). Note: `00-REVIEW.md` WR-06 flags the `tests/*` exemption as masking real dead code (e.g. unused `os`, `ParagraphStyle` in `tests/data/corpus/generate_corpus.py:6,18`) — do not add new unused imports relying on this exemption; remove dead imports instead.
- No `ruff format --check`, no mypy, no coverage gate in CI (gap noted in `00-REVIEW.md` WR-08).

**Section banners:**
- Use the dashed banner comment to separate logical sections, with surrounding blank lines. Copy this exact shape when adding a section:
  ```python
  # ------------------------------------------------------------------
  # Sidebar — model status + document upload
  # ------------------------------------------------------------------
  ```
  Observed in `main.py:26-28,38-40,55-57,84-86,178-180` and `vector_index.py:36-38,146-148,197-199,209-211`, plus the `# Run` footer block (`main.py:248-253`, `vector_index.py:224-226`, `pdf_reader.py:81-83`).
- Test modules open with the same banner stating scope: `# Unit Tests for VectorIndex` (`tests/test_vector_index.py:1-4`), `# Unit Tests for PdfReader` (`tests/test_pdf_reader.py:1-4`), `# Unit Tests for LocalEmbedding` (`tests/test_local_embedding.py:1-4`), `# Unit Tests for AiModel (local_llm.py)` (`tests/test_local_llm.py:1-4`), `# Pytest Shared Fixtures & Mocking Seams` (`tests/conftest.py:1-4`), `# Test Corpus Generator` (`tests/data/corpus/generate_corpus.py:1-4`), `# Baseline Performance Benchmark Script` (`scripts/benchmark_baseline.py:1-6`). New test/script files must open with the same banner.

## Import Organization

**Order (observed, follow this):**
1. Standard library (`os`, `tempfile`, `datetime`, `re`, `math`, `typing`, `json`, `sys`, `time`, `io`, `pathlib`).
2. Third-party (`streamlit`, `dotenv`, `sentence_transformers`, `pypdf`, `langchain_text_splitters`, `groq`, `numpy`, `psutil`, `reportlab`, `pytest`).
3. First-party / local modules (`local_llm`, `local_embedding`, `pdf_reader`, `vector_index`).

**Examples:**
- `main.py:14-23` — stdlib block, blank line, third-party block, blank line, local block.
- `vector_index.py:11-12` — stdlib-only module (`math`, `typing`).
- `local_llm.py:1-9` — `os`, `streamlit`, local imports, then guarded `groq` import in `try/except ImportError` (`local_llm.py:6-9`).
- `pdf_reader.py:1-5` — `re`, `pypdf`, blank lines, `langchain_text_splitters`.
- `tests/conftest.py:6-10` — stdlib (`os`, `pathlib`), `unittest.mock`, third-party (`numpy`, `pytest`).
- `scripts/benchmark_baseline.py:8-13` — stdlib (`json`, `os`, `sys`, `time`, `pathlib`, `psutil`), then `sys.path.insert(0, REPO_ROOT)` bootstrap (`scripts/benchmark_baseline.py:16-17`), then local imports (`pdf_reader`, `vector_index`). The deferred `from sentence_transformers import SentenceTransformer` inside `run_benchmark` (`scripts/benchmark_baseline.py:66`) is intentional (measure model-load time separately) — do not hoist it.

**Path aliases:**
- None. All imports are top-level absolute (`from vector_index import VectorIndex` in `local_embedding.py:8`).

**Exception to the rule:**
- One function-level import exists: `import io` inside the upload loop (`main.py:131`). Do not copy this — hoist new stdlib imports to the top-level block. The top-level pattern is the convention; the inline `import io` is a one-off.

## Error Handling

**Guard-clause validation (primary pattern — `vector_index.py`):**
- Fail fast with `TypeError` for wrong types and `ValueError` for bad values, before mutating state. New `VectorIndex` methods must follow this:
  ```python
  # `vector_index.py:77-84`, `vector_index.py:126-132`
  if not isinstance(vector, list) or not all(isinstance(x, (int, float)) for x in vector):
      raise TypeError("Vector must be a list of numbers.")
  if k <= 0:
      raise ValueError("k must be a positive integer.")
  ```
- Full guard inventory to mirror: metric whitelist (`vector_index.py:27-28`), missing embedding fn (`vector_index.py:51-52,115-116`), non-dict document / missing `content` key / non-string content (`vector_index.py:53-60,81-84`), dimension lock-in and mismatch (`vector_index.py:87-92,126-129`), bad query type (`vector_index.py:121`), vector-length checks in every distance helper (`vector_index.py:161-162,179-180,202-203`).
- Empty-store behaviour: `search()` returns `[]` instead of raising when nothing is indexed (`vector_index.py:110-111`).
- Tests assert every guard with `pytest.raises(<Type>, match="<message fragment>")` — see `test_add_vector_guards` (`tests/test_vector_index.py:47-74`) and `test_vector_index_initialization` (`tests/test_vector_index.py:10-18`). New guards must add a matching `pytest.raises` case with the exact message fragment.

**Optional-dependency pattern (`local_llm.py:6-9,19-21`):**
```python
try:
    from groq import Groq
except ImportError:
    Groq = None
# ... later, in AiModel.__init__:
if not Groq:
    raise ImportError("groq package is missing. Please run `pip install groq`.")
```
- Use this shape for any new optional third-party import: `try/except ImportError → None` at top, explicit `ImportError` with install hint at use site.

**Config-failure pattern (`local_llm.py:24-30`):**
- Missing `GROQ_API_KEY` raises `ValueError` with remediation text naming both secret locations. New required-config checks must raise with the same "what + where to set it" message shape. Covered by `test_ai_model_missing_key_raises` (`tests/test_local_llm.py:11-18`), which deletes the env var via `monkeypatch.delenv("GROQ_API_KEY", raising=False)` and asserts `match="GROQ_API_KEY is not set"`.

**UI-level handling (`main.py:134-139`):**
- Per-file `try/except Exception as e` around `PdfReader` + `get_paragraphs()`, reporting via `st.error(f"... (Error: {e})")` then `continue` so one bad PDF never aborts the batch. New per-document processing must use this isolate-and-continue shape, never a bare `except:`.

**Script-level handling (`scripts/benchmark_baseline.py:34-36,170-171`):**
- Fail fast with a message + `sys.exit(1)` when a prerequisite is missing (corpus PDF absent). Wrap new script entry points in `if __name__ == "__main__":` calling a single `run_*()` function, mirroring `run_benchmark()`.

**Defensive indexing (`main.py:151`, `local_llm.py:49-52`, `vector_index.py:186-189`):**
- `paragraphs[-1]["page"] if paragraphs else 0` guards empty PDFs; `if chat_history:` / `if last_user_msgs:` guards history contextualisation; zero-magnitude vectors return `0.0`/`1.0` instead of dividing by zero. Preserve these guards when touching the same code. Zero-magnitude behaviour is pinned by `test_zero_magnitude_vector` (`tests/test_vector_index.py:105-109`).

## Logging

**Framework:** `print()` to stdout/stderr only. No `logging` module, no log levels, no structured logging.

**Patterns:**
- Lifecycle prints with module prefix: `print(f"[LocalEmbedding] Loading {self.model_name}...")` (`local_embedding.py:22`), `print("[LocalEmbedding] Model ready.")` (`local_embedding.py:24`), `print(f"[LocalEmbedding] Indexed {len(chunks)} chunks.")` (`local_embedding.py:59`), `print(f"Successfully extracted text from {self.filename}. Total characters: {len(self.pages_text)}")` (`pdf_reader.py:60`), `print("running checks to make sure everything is good...")` (`local_llm.py:16`).
- Benchmark progress prints use numbered-stage headers (`[1/4]`, `[2/4]`, …) plus `[Memory]` / `[Output]` tags (`scripts/benchmark_baseline.py:29-39,42,57,65,95,126,166`). New long-running scripts must use the same staged-print shape.
- Corpus generator prints per-file byte sizes at completion (`tests/data/corpus/generate_corpus.py:211-214`).
- User-facing feedback goes through Streamlit, never `print`: `st.error` / `st.info` / `st.success` / `st.status` / `st.write` (`main.py:96,129,138,144,167`). Rule: `print()` for developer diagnostics, `st.*` for anything the user should see.
- Tests assert behaviour, never log output — no `caplog`/`capsys` usage in the suite.

## Function Design

**Size:**
- Small single-purpose methods (5–25 lines). Largest functions are UI layout blocks in `main.py` (sidebar ~90 lines, chat handler ~40 lines) — these are sequential Streamlit layouts, not logic to extract, unless adding genuinely new UI sections.
- Test functions are single-behavior (5–30 lines each); one `test_*` per behavior, not one mega-test per class. Follow `tests/test_vector_index.py` (7 focused tests) as the model.

**Parameters:**
- Keyword-friendly with sane defaults: `prompt: str = "tell me what is this pdf about", local_embedding=None, chat_history=None` (`local_llm.py:36`); `k: int = 3` (`local_embedding.py:61,67`, `vector_index.py:97`); `model_name: str = "all-MiniLM-L6-v2", distance_metric: str = "cosine"` (`local_embedding.py:13`). New retrieval parameters must default so existing call sites keep working.
- Dual-type flexibility where the codebase already does it: `PdfReader.__init__(self, file_or_path, filename=None)` accepts a path string, bytes stream, or file object (`pdf_reader.py:10-21`); `VectorIndex.search(query: Any, ...)` accepts a string or a precomputed vector (`vector_index.py:97-121`); `LocalEmbedding.build_index(chunks: list)` accepts `list[str]` or `list[dict]` (`local_embedding.py:42-54`). Extend with the same accept-both-types + normalise-early shape.
- Fixtures take `monkeypatch` and return the mock handle for call-assertion: `mock_groq_client(monkeypatch) -> mock_client`, `mock_sentence_transformer(monkeypatch) -> mock_model` (`tests/conftest.py:20-81`). Request fixtures by name as test args (`def test_ai_model_prompt_assembly(fake_env_groq_key, mock_groq_client):` in `tests/test_local_llm.py:21`).

**Return values:**
- Data methods return plain containers: `list[dict]` chunks with `content`/`filename`/`page`/`chunk_id` keys (`pdf_reader.py:51-56`), `list[tuple[dict, float]]` of `(document, distance)` sorted ascending (`vector_index.py:97-144`), joined context string (`local_embedding.py:67-72`).
- Generation is a token generator (`yield chunk.choices[0].delta.content` in `local_llm.py:80-82`) consumed by `st.write_stream`, which returns the full string (`main.py:239`). New LLM entry points must yield strings (not return a completed string) to preserve streaming. Pinned by `test_ai_model_streaming_yield` (`tests/test_local_llm.py:65-80`).
- No `None`-on-error: failures raise, empty results return `[]`/`""`-adjacent empties (`vector_index.py:110-111`, `local_embedding.py:46-47`).
- Corpus builders return `None` and write to disk; `generate_all_corpus_files() -> dict[str, Path]` maps names to paths (`tests/data/corpus/generate_corpus.py:187-207`).

## Module Design

**Exports:**
- Single public class per module, imported by name — no `__all__`, no factories, no re-exports. Wire new cross-module dependencies the same way (`from x import Y` at top level).
- Benchmark script exposes `run_benchmark()` + `get_current_rss_mb()` and runs only under `if __name__ == "__main__":` (`scripts/benchmark_baseline.py:23-28,170-171`). Corpus module exposes `generate_all_corpus_files()` under the same guard (`tests/data/corpus/generate_corpus.py:210-214`). Importing these modules must never trigger work.

**Barrel files:**
- None and not wanted: the flat layout means a new module is just a new root-level file plus an import where used. New test files are new `tests/test_*.py` files (auto-discovered via `python_files = ["test_*.py"]` in `pyproject.toml:15`).

## Test Conventions (must-follow)

**Fixtures — use `tests/conftest.py`, do not re-mock inline:**
- `fake_env_groq_key` — sets `GROQ_API_KEY` via `monkeypatch.setenv` (`tests/conftest.py:13-16`). Use in every `AiModel` construction test.
- `mock_groq_client` — patches the exact symbol `AiModel` calls (`local_llm.Groq` via `monkeypatch.setattr(local_llm, "Groq", lambda api_key=None: mock_client)`) and yields 5 canned tokens `["This ", "is ", "a ", "grounded ", "answer."]` through `choices[0].delta.content` (`tests/conftest.py:20-48`). Assert via `mock_client.chat.completions.create.call_args[1]` (`messages`, `model`, `stream`) as in `tests/test_local_llm.py:46-62`.
- `mock_sentence_transformer` — patches the exact symbol `LocalEmbedding` calls (`local_embedding.SentenceTransformer`), returns deterministic 384-dim L2-normalised `float32` vectors keyed off text length (`tests/conftest.py:51-81`). Assert `store._vector_dim == 384` after `build_index` (`tests/test_local_embedding.py:26-28`).
- `sample_pdf_path` — resolves `tests/data/corpus/clean_digital.pdf` (`tests/conftest.py:84-88`). Note `tests/test_pdf_reader.py` currently duplicates this with its own `CORPUS_DIR` constant instead of using the fixture (known duplication, `00-REVIEW.md` IN-05) — new PDF tests should prefer the fixture.
- Tests never hit network, GPU, or disk-external resources: Groq is mocked, `SentenceTransformer` is mocked, corpus PDFs are generated locally by `generate_corpus.py` and read from disk. The only unmocked heavy path is `scripts/benchmark_baseline.py`, which intentionally loads the real model (not a test).

**Mocking rules:**
- Mock at the seam the production code calls (module attribute), not the library root: `local_llm.Groq`, not `groq.Groq`; `local_embedding.SentenceTransformer`, not `sentence_transformers.SentenceTransformer`. Use `monkeypatch.setattr` (auto-reverted), never manual patch/unpatch.
- `MagicMock` for injected collaborators: `mock_embedding = MagicMock(); mock_embedding.get_context.return_value = "..."` (`tests/test_local_llm.py:26-27`). Assert collaboration with `assert_called_once()` and inspect `call_args`.
- What NOT to mock: `VectorIndex` math (pure stdlib — test directly with hand-computed vectors, `tests/test_vector_index.py:21-44`); `RecursiveCharacterTextSplitter` behaviour (assert observable chunk size/metadata, `tests/test_pdf_reader.py:29-43`).
- Known coupling (accepted): `tests/test_vector_index.py` binds to private API (`_cosine_distance`, `_euclidean_distance`, `_distance_metric`, `_vector_dim`) — white-box by design for the math-guard suite (`00-REVIEW.md` IN-02). Do not extend private-API coupling to other modules.

**Assertion idioms:**
- Float math: `assert pytest.approx(actual, abs=1e-5) == expected` (`tests/test_vector_index.py:27,44,96`).
- Errors: `with pytest.raises(<ExcType>, match="<message fragment>"):` (`tests/test_vector_index.py:17-18,52-65`, `tests/test_local_llm.py:17-18`).
- Corpus preconditions: `assert pdf_path.exists(), "Corpus file ... must exist"` before reading (`tests/test_pdf_reader.py:18`) — failure message tells the runner to run the generator first.
- Streaming: `tokens = list(generator)` then compare exact token list and joined string (`tests/test_local_llm.py:78-80`).
- Unused-import tolerance in tests comes from the ruff `tests/*` `F401`/`F841` exemption — still keep test imports minimal; `pytest` and `MagicMock` imports in test files are used.

**Corpus generation rules:**
- `tests/data/corpus/generate_corpus.py` is deterministic, offline, fixed filenames — use `reportlab` only (stdlib + reportlab, no network). Scanned-sample generator must use only vector rects (no `drawString`) so the zero-text property the scanned test depends on is structural (`tests/data/corpus/generate_corpus.py:130-147`). Corrupt fixture must be raw invalid bytes, not a valid PDF (`tests/data/corpus/generate_corpus.py:181-184`). Regenerate via `python tests/data/corpus/generate_corpus.py` (CI runs this before pytest).

## Streamlit Idioms (must-follow)

- `st.set_page_config(...)` is the very first Streamlit call (`main.py:30-35`) — never insert a Streamlit call above it.
- Initialise all `st.session_state` keys via the key/default loop (`main.py:45-52`); add new keys there, never lazily mid-layout.
- Heavy singletons go behind `@st.cache_resource` (`main.py:59-67`); per-`load_dotenv()`-before-read ordering inside the cached function matters because `AiModel.__init__` reads the env.
- Render pattern: `with st.sidebar:` layout, `st.status` for staged work with `.update(label=..., state="complete", expanded=False)` on completion (`main.py:96-98,158-162`), `st.chat_message` + `st.markdown` for history replay (`main.py:196-200`), `st.chat_input(..., disabled=(...))` for gated input (`main.py:204-207`), `response_stream → st.write_stream(response_stream) → append to history` (`main.py:233-245`).
- State mutation ends with `st.rerun()` after batch updates (`main.py:112,156`).
- Missing-key test validity depends on no `secrets.toml` in the test env (`st.secrets[…]` raising `FileNotFoundError`, caught at `local_llm.py:26`) — never commit a secrets file that would silently change this path (`00-REVIEW.md` per-file note on `tests/test_local_llm.py`).

## Config Patterns (must-follow)

- `load_dotenv()` is called inside the cached loader (`main.py:66`), and `AiModel` reads `st.secrets["GROQ_API_KEY"]` first with `except (KeyError, FileNotFoundError)` fallback to `os.environ.get("GROQ_API_KEY")` (`local_llm.py:23-27`). New secrets must follow this exact precedence: `st.secrets` → `.env`/`environ` → raise `ValueError` naming both locations.
